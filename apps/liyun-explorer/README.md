# 理韵寻踪 · 北理校园探索

以良乡校园地图为基础的 Web 探索游戏，采用玉绿、宣纸、细金线与剪纸山水。工程使用 React、TypeScript、Vite、p5、Framer Motion、GSAP、Radix 和 Zustand；可选 Node / SQLite 服务提供账号与云存档。

2026-11-03本轮开发和本地自动化验收已收口，入口为[场景约定](docs/SCENE.md)、[HUD交接](docs/hud-handoff.md)、[验收索引](docs/QA.md)与[TODO](TODO.md)。原[V2方案](docs/UI-REFACTOR-PLAN-V2.md)保留设计历史；最新要求已落实为**派蒙式左侧抽屉，右侧校园世界保持可见**。最终153项单测及服务端10+9项通过，原始构建产物20,908,923B（19.940MiB），首屏静态JS图gzip214,068B，字体946字符联合覆盖0缺字；细分范围见[总证据](../../qa/ui-implementation-20261103/README.md)。本轮已按所有者新授权于20:08发布[生产入口](https://liyun.studentop.cn:14355/)，版本`0a068ea850ed2b2b33c325f1`，公网8项及浏览器5项简检通过，见[发布记录](docs/LIYUN-UI-RELEASE-20261103.md)。真机与现场确认按用户安排由队员稍后执行，未记为通过。

## 本地运行

在线协作编辑入口为[校园内容工坊](https://liyun.studentop.cn:14355/studio/)，操作见[团队指南](docs/STUDIO-GUIDE.md)。支持增删景点、介绍与照片、分区/打卡范围预览、中键平移、闭合及覆盖整理；草稿自动同步到团队和服务器，预览确认后再发布。本地可双击 `start-studio.cmd` 或运行 `npm run studio`。这是用户后续新增的在线版本要求，覆盖旧文档中的“作者工具不发版”限制；多人端验收由用户手动完成。

需要 Node.js 22.12 或更新的受支持版本。从仓库根优先使用[统一启动器](../../tools/dev-workspace.mjs)。在本应用目录单独启动：

```sh
npm ci
npm run dev
```

开发地址为 [127.0.0.1:5174](http://127.0.0.1:5174/)，仅监听回环且使用 strictPort；冲突时退出，不复用或停止不明服务。构建预览为 [127.0.0.1:4174](http://127.0.0.1:4174/)。旧 5173 / 4173 与 8080 SSH 转发不属于本应用运行入口。本轮隔离自动化测试另用 5176；它不是新的默认端口。

```sh
npm test
npm run verify:map
npm run build
npm run preview
```

单独运行账号服务时，先确认没有自己启动的完整模式占用 8787：

```sh
npm run server
npm run test:server
```

前端通过同源 `/api` 访问服务，Vite 开发代理转发到回环账号服务。正常运行不需要重建底图、音频或字体；素材脚本不自动安装工具。当前回环服务不开放手机局域网访问，真实设备 HTTPS 访问与授权说明见 [REAL-LOCATION.md](docs/REAL-LOCATION.md)。

## 探索与界面

- 拖动地图移动视野；滚轮、双击或双指缩放。拖动灵敏度、缩放上限和双击倍率由设置持久化。
- 点击地标查看范围与定位状态。设备位置须新鲜、精度达标且在打卡范围内，才能确认打卡；未定位、过期、过远、精度不足和重复打卡不会增加进度。当前不是正式考勤或防作弊认证。
- 点击“定位到我”按需开启定位和方向。有效方向显示三角指针，不可用时保留无指向标记；拖动会取消跟随。实时 GPS、精度与朝向不进入本机或云端存档。
- 左上校门徽章和右上账户入口打开左侧旅途抽屉。身份、收录和探索度读取真实状态；未开放宫格显示可见标识。“关于”进入设置的其他分类，不再跳回地图。
- 设置是独立全屏页，提供控制、按键、图像、声音、消息、账户、数据、其他八类。分类悬停有浅亮底，选中有菱形描边、迁移高亮与一次性扫光；减少动态 / 强闪光偏好会收敛装饰。参考视频关键帧与连续采样见[菜单设置记录](../../qa/ui-implementation-20261103/menu-settings/README.md)。
- 菜单、设置、Select 和确认框各自管理焦点与 Escape：先关闭内层选项或确认，再由设置返回菜单、菜单返回地图。首次懒加载前保存实际触发者，完整退场后归还焦点。浏览器全屏请求 `document.documentElement`，确保挂载在 body 下的 Radix Portal 仍在全屏树内。
- 活动与图鉴保留现有入口；图鉴 / 地标正文分别懒载，通用弹窗外壳和入场表单留在 HUD。A / C / M / F / L 分别打开活动、图鉴、回中、全屏和定位；输入文字和非地图页面时让出热键。

页面入场从三首用户提供的配乐中选择一首；配乐、音量、曲目与界面反馈音均有设置。浏览器音频、全屏和方向授权仍取决于设备能力。

## 画质、播报与演出

低 / 高 / 极致三档预设统一控制像素密度、帧率、粒子、云纹、模糊、阴影、墨散和环境装饰。单项修改保留 `baseQualityPreset`，标记具体自定义项；系统与游戏的减少动态偏好取或，实际限制不会反写用户配置。HUD 支持 90% / 100% / 112% 缩放。

自动降级默认开启，只在地图有效活动状态且当前为高 / 极致时采样：首窗 5 秒，后续 30 秒，连续两个有效窗口低于 26fps 才降档。隐藏、竖屏、菜单、设置、弹窗和演出会丢弃采样窗口；关闭后移除采样，保留当前画质。“恢复原档”恢复本轮降级前记录的档位。这是实现策略，不能当作手机实测性能。

播报为 FIFO 队列，每条记录自己的停留时长；遮挡时保留队首，恢复显示后重新计时。演出也有独立队列，打卡先提交存档，再经过正常 3.2 秒 / 减少动态 0.4 秒前奏进入呈现。主视觉时间轴正常 **5.2 秒**、减少动态 **1 秒**、连续发现快版 **2.4 秒**。时间轴结束后保留阅读终态，需点击“继续探索”、任意处、Escape 或 Space 离开；跳过不撤销进度，关闭演出设置不会丢失已提交状态。

Framer 管界面与弹窗的进入、布局和退场；GSAP 管分区墨散与演出内部时间轴；p5 / Canvas 管环境绘制。两种引擎不同时写同一元素的 transform。

## 分区与团队标定

8 个分区具有独立 `unlockedRegionIds`，未启区域以不透明纸墨遮罩覆盖，地标层仍位于其上。解锁后的墨散与存档相互独立，刷新恢复不会从地标集合强制覆盖合法区域状态。当前外边界和分区是 **recommended 推荐初稿，尚未现场确认**；定位 `support_polygon_uv` 只表示采样覆盖，不是校界或游戏范围。

团队工具仅在本地开发环境开放，入口为[`?tool=calibration`](http://127.0.0.1:5174/?tool=calibration)，开发服务的`/calibrate.html`跳至同一路由。完整编辑器及其静态包装页不进入生产dist，正式设置页也不显示作者入口；生产误入工具URL时只显示本地入口提示并保持存档隔离。工坊草稿与游戏存档隔离，不自动取GPS；导出不改游戏。现场确认、CLI dry-run与显式`--apply`见[作者指南](src/calibration/AUTHORING.md)。

冻结 v0.4 底图、SDK / 模型和 `src/data.ts` 公共 UV 不改动。已确认显示点通过副本投射对齐，云端玩家锚点继续使用公开固定坐标。新生成的 8 张地标插画与墨纹用于概念占位，不是实景照片或位置证据；详见[素材说明](docs/ASSETS.md)。

## 账户与数据

登录使用昵称、游戏 ID 与访问口令；首次 ID 建档，已有 ID 验证口令。游客入口始终保留。账户信息在抽屉与设置中显示，退出或转登录会关闭遮挡路由。云端首次读取暂时失败时保留本机状态并暂停自动 PUT，先重试读取，避免旧本机进度覆盖云端。

设置中的三个数据操作分别处理：

| 操作 | 当前行为 |
| --- | --- |
| 重置探索进度 | 独立二次确认；清空地标 / 分区，保留设置；登录时串行提交空进度，避免旧自动保存晚到覆盖 |
| 清空本机存档 | 独立二次确认；移除当前 / 旧探索与本机会话，退出到入口；不删除云端旅途 |
| 导出 JSON | 从当前有效内存状态清洗导出，普通页面没有本地键也可导出；不直接读取固定旧键 |

恢复默认设置另有确认，仅重置偏好。普通键名仍为 `liyun.exploration.v2`，结构为 `version: 3`；区域解锁和完整设置在本机 / 云端共享白名单下恢复。游客数据不跨浏览器、来源或设备同步。完整契约与运行保护见 [ACCOUNT.md](docs/ACCOUNT.md)和 [server/README.md](server/README.md)。

## 开发验收入口

仅 Vite 开发环境且 `qa=1` 提供 `window.__LIYUN__`。当前 **所有 QA 模式均隔离普通探索与会话存储**，不再保留旧版“不带 preset 仍读写普通存档”的行为。

| 入口 | 状态 |
| --- | --- |
| `/?qa=1&preset=fog` | 全部未打卡，0%，隔离存档与账号 |
| `/?qa=1&preset=explored` | 前 7 处已发现，37%，隔离存档与账号 |
| `/?qa=1` | 空探索演示，隔离存档与账号 |

查询包括 `getState / getCamera / getEvent / getUi / getRegions`；操作包括 `select / discover / setCamera / setPreset / setEntered / showPanel / setRoute / reset / freeze / setSettings / setQualityPreset / unlockRegion / previewCinematic`。例如 `unlockRegion('beihu')` 或 `previewCinematic('region', 'beihu')` 用于独立场景验收；`discover` 仍走位置校验，不绕过 GPS。`freeze(offsetMs)` 固定当前发现事件相对时间，`freeze()` 恢复。生产构建不提供此接口。

有效局部证据：菜单设置 114 项、HUD 面板 45 项、主应用会话 / 数据 37 项与标定 UI 33 项，入口见 [QA.md](docs/QA.md)。这些数量覆盖不同范围，不能相加成全站总验收。最终字体 / 构建 / 世界演出 / 主题范围已本地收口，手机触摸、现场 GPS和手机性能仍未实测。本轮生产发布依据单独的[2026-11-03回执](docs/LIYUN-UI-RELEASE-20261103.md)；历史定位融合另见[既有记录](../../docs/PR2-LOCATION-RELEASE-20261028.md)。
