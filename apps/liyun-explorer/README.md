# 理韵寻踪 · 北理校园探索

以良乡校园地图为基础的本地 Web 探索界面。美术采用二次元新国风赛璐璐剪纸：清晰色块、分层轮廓、竹绿月白、细金边与奶油云纹。工程使用 React、TypeScript、Vite 和 p5.js，交付源码与本地构建，不含线上部署。

## 本地启动

需要 Node.js 22.12 或更新的受支持版本。集中仓库中的实际目录是 `apps/liyun-explorer`（不再是旧 `web`）。依赖由负责人统一安装，推荐从仓库根使用[统一启动器](../../tools/dev-workspace.mjs)；以下为在本应用目录单独启动的兼容命令：

```sh
npm ci
npm run dev
```

打开 <http://127.0.0.1:5174/>。Vite 仅监听回环 127.0.0.1，固定 5174 且 strictPort；冲突立即失败，不复用或停止不明服务。旧 5173 / 4173 与 8080 SSH 转发不可碰。点击「进入校园」后开始探索，手机视口请横屏；当前回环服务不开放局域网手机访问。

```sh
npm test
npm run build
npm run preview
```

`npm test` 运行几何、存档与事件时序单元测试；`npm run build` 先检查 TypeScript，再输出 `dist/`；`npm run preview` 严格监听 <http://127.0.0.1:4174/>。5174 是开发服务，4174 是构建预览，不能使用旧 5173 / 4173。开发调试接口只在前者启用，两者存档互相独立。正常运行不需要重建地图、音频或字体；素材脚本不自动安装外部工具。

账号与云端存档是可选的（见下文「账号与云端存档」）。需要时另起一个零依赖 Node 服务：

```sh
npm run server        # 监听 127.0.0.1:8787，前端经 /api 同源访问（开发由 Vite 反代）
npm run test:server   # 后端存储层与接口的 node:test 单元测试
```

接口契约与设计见 [docs/ACCOUNT.md](docs/ACCOUNT.md)，服务端见 [server/README.md](server/README.md)。

## 探索方式

- 拖动地图移动视野；鼠标滚轮、双击地图或手机双指手势缩放。
- 点击地标查看详情，再点击「前往探索」，观看行进、流光与云雾散开。地标和探索进度随即保存。
- 点击左上标识或右侧罗盘回到默认校园视角。设置、指引、图鉴位于左下角。
- 本次页面首次点击「进入校园」时，从三首用户提供的 BGM 随机选择一首。设置中可切换曲目、音量与音乐开关。
- 设置提供画面质量、减少动态、全屏与重置进度。重置需要在面板内再次确认；全屏和横屏锁定取决于浏览器能力。

存档保存在当前浏览器、当前站点来源的 `localStorage`，键名为 `liyun.exploration.v1`。刷新会恢复发现状态、玩家位置与设置；相机视角重新采用默认构图。存储不可用时仍可在当前页面内探索。默认（游客模式）不跨设备同步：更换浏览器、端口或设备不会同步存档。

## 账号与云端存档

入口卡片支持「昵称 + 学号」登录（无密码，学号唯一，首次登录自动建档）。登录后：

- 打卡记录（每个已发现地标 + 首次打卡时间）与收集进度（完整 `ExplorationState` 快照）持久化到服务端 SQLite，退出后重新登录会拉回自己的历史数据，跨设备可同步。
- 底部 `UID` 显示真实 `昵称 · UID`；设置面板可查看账号、退出登录或从游客切换为登录。
- 后端不可达时自动退化为游客模式（localStorage），行为与无账号版本一致；「游客模式」入口始终保留，不强制登录。

实现与接口见 [docs/ACCOUNT.md](docs/ACCOUNT.md)，部署见 [deploy/pi-liyun/ACCOUNT-API.md](../deploy/pi-liyun/ACCOUNT-API.md)。

## 当前内容范围

首版有 8 个可探索地标，初始文萃楼已发现，探索度为 3%；全部当前地标点亮后为 45%。顶部「收录 /36」是完整游戏目标总数的 Mock，当前图鉴只有上述 8 项。体力 164/200、在线 4 人、第三章与节气日期为界面演示值；多人同行、异闻等入口提供本地说明面板。

真理之塔是游戏虚构探索信标。地图位置使用预置校园地图坐标；本版没有接入真实 GPS、相机或多人服务器；账号与云端存档为可选能力（见上节），未部署后端时自动退化为游客模式。

## 开发验收入口

仅开发服务支持以下固定预设，跳过入场与音频，并隔离普通用户存档：

| 地址 | 初始状态 |
| --- | --- |
| `/?qa=1&preset=fog` | 文萃楼已发现，探索度 3% |
| `/?qa=1&preset=explored` | 除国防教育主题公园外的 7 处已发现，探索度 37% |

开发模式且带 `qa=1` 时，`window.__LIYUN__` 提供 `getState`、`getCamera`、`select`、`discover`、`setCamera`、`setPreset`、`showPanel`、`setEntered`、`reset`、`freeze`。在发现事件进行时调用 `freeze(1600)`，可固定到该事件开始后 1600 毫秒；`freeze()` 恢复。仅使用 `qa=1` 而没有固定 `preset` 时，仍会读写普通存档。生产构建不开放该调试接口。

上述命令与入口用于复核，不代表已经完成全部浏览器、设备或性能验收。最终实际测试范围以交付验收记录为准。
