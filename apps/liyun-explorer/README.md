# 理韵寻踪 · 北理校园探索

以良乡校园地图为基础的 Web 探索界面。美术采用二次元新国风赛璐璐剪纸：清晰色块、分层轮廓、竹绿月白、细金边与奶油云纹。工程使用 React、TypeScript、Vite 和 p5.js；账号与云存档使用可选 Node / SQLite 服务。定位与账号合并后的已记录发布见[融合发布记录](../../docs/PR2-LOCATION-RELEASE-20261028.md)，后续修改仍需重新验收和授权发布。

2026-10-28 新增 FE-01 真实校园定位：直接复用 10月26日 v0.4 标定包的完整无字地图、WGS84 映射 SDK 和已选模型，保留当前所有地标 UV。运行步骤、验证证据与手机实测清单见 [真实定位接入说明](docs/REAL-LOCATION.md)。

同日按用户手机定位通过后的反馈，新增「一次点击定位并显示朝向」：无需单独的朝向按钮；当前位置指针随指南针转动。系统对定位和方向的授权可能分别弹窗，网页不能承诺只有一个系统授权框。

当前位置现使用月白与玉绿切面、细金描边的三角指针，随有效手机朝向旋转，并保留淡金绿色光晕。方向不可用或定位不可靠时改用无指向的菱形位置标记，不显示虚假的固定箭头。

## 本地启动

需要 Node.js 22.12 或更新的受支持版本。集中仓库中的实际目录是 `apps/liyun-explorer`（不再是旧 `web`）。依赖由负责人统一安装，推荐从仓库根使用[统一启动器](../../tools/dev-workspace.mjs)；以下为在本应用目录单独启动的兼容命令：

```sh
npm ci
npm run dev
```

打开 <http://127.0.0.1:5174/>。Vite 仅监听回环 127.0.0.1，固定 5174 且 strictPort；冲突立即失败，不复用或停止不明服务。旧 5173 / 4173 与 8080 SSH 转发不可碰。点击「进入校园」后开始探索，手机视口请横屏；当前回环服务不开放局域网手机访问。手机定位通过用户自行建立的HTTPS隧道访问，保留 `.trycloudflare.com` Host支持，详见[真实定位说明](docs/REAL-LOCATION.md)。

```sh
npm test
npm run build
npm run preview
```

`npm test` 运行几何、存档与事件时序单元测试；`npm run build` 先检查 TypeScript，再输出 `dist/`；`npm run preview` 严格监听 <http://127.0.0.1:4174/>。5174 是开发服务，4174 是构建预览，不能使用旧 5173 / 4173。开发调试接口只在前者启用，两者存档互相独立。正常运行不需要重建地图、音频或字体；素材脚本不自动安装外部工具。

账号与云端存档是可选玩法（见下文「账号与云端存档」）。仓库统一启动器在完整模式下会自动启动零依赖 Node 账号服务，并验证健康状态，前端仍通过同源 `/api` 访问。单独启动本应用时，可另外运行以下兼容命令；先退出自己启动的完整模式，避免占用 8787：

```sh
npm run server        # 监听 127.0.0.1:8787，前端经 /api 同源访问（开发由 Vite 反代）
npm run test:server   # 后端存储层与接口的 node:test 单元测试
```

接口契约与设计见 [docs/ACCOUNT.md](docs/ACCOUNT.md)，服务端见 [server/README.md](server/README.md)。

## 探索方式

- 拖动地图移动视野；鼠标滚轮、双击地图或手机双指手势缩放。
- 点击地标查看打卡范围与实时距离。开启定位、设备报告到达地标范围内且精度满足要求后，才能点击「确认打卡」；成功后播放流光与云雾散开，并保存进度。未定位、位置过期、定位精度不足或距离过远时均不能打卡。当前没有独立校园边界 polygon；图幅内只表示映射落在图片矩形中，不是校界判定。打卡依据地标距离圈，不宣称是防伪定位或正式考勤。
- 点击「定位到我」后，在同一次点击中按需开启定位和方向访问，地图显示实际位置、精度范围、朝向扇形及最近真实点位的直线距离。稍微放平手机，扇形表示屏幕上边缘的方向；左右横屏均有补偿。方向授权被拒绝或设备没有指南针时，仍可正常定位。拖动地图会取消跟随，再点击定位按钮可回到当前位置；已有方向授权在本页面恢复时复用。停止或切后台时同时停止两类监听，返回时主动继续。
- 点击标题或右侧罗盘时，有新鲜实际位置则回到实际位置，否则回到默认校园视角。左下为活动一览与图鉴；右上「收录」也可打开图鉴；设置并入个人主页，点左上校门徽章打开。
- 本次页面首次点击「进入校园」时，从三首用户提供的 BGM 随机选择一首。设置中可切换曲目、音量与音乐开关。
- 设置提供画面质量、减少动态、全屏与重置进度。重置需要在面板内再次确认；全屏和横屏锁定取决于浏览器能力。

游客存档保存在当前浏览器、当前站点来源的 `localStorage`，当前键名为 `liyun.exploration.v2`。首次进入所有点位均未打卡、进度为0%；刷新会保留之后通过位置校验完成的记录。旧 `v1` 是默认文萃楼完成与任意点击探索的演示存档，升级时仅迁移设置，不计入真实打卡；旧数据保留在原键下。相机视角重新采用默认构图。游客存档不跨浏览器、端口或设备同步；存储不可用时仍可在当前页面内探索。

## 账号与云端存档

入口卡片支持「昵称 + 学号/游戏ID + 访问口令」，首次注册建档，之后必须验证口令才能读取同一云端存档。昵称不要填写真实姓名，可用测试标识代替真实学号；这不是学校实名验证或正式考勤系统。登录后：

- 打卡记录（每个已发现地标 + 首次打卡时间）与收集进度（完整 `ExplorationState` 快照）持久化到服务端 SQLite，退出后重新登录会拉回自己的历史数据，跨设备可同步。
- 顶部与个人主页显示当前昵称，右下显示账号 UID 或「游客 · 本机存档」；个人主页可查看账号、退出登录或从游客切换为登录。
- 后端不可达时自动退化为游客模式（localStorage），行为与无账号版本一致；「游客模式」入口始终保留，不强制登录。

实现与接口见 [docs/ACCOUNT.md](docs/ACCOUNT.md)，部署见 [部署说明](../../deploy/pi-liyun/ACCOUNT-API.md)。

## 当前内容范围

当前有8个可探索地标，初始全部未打卡、探索度为0%；全部当前地标点亮后仍按原界面权重合计45%。收录总数来自实际地标，身份来自当前账号或游客，不显示假在线人数、固定 UID、体力或旧主线条幅。

左下「活动一览」打开横屏卷轴目录，五个主题可切换。未上线活动标为预告，奖励只作构想展示；北湖与图书馆可进入现有地图预览并返回，往期纪事回顾实际图鉴。设置继续位于左上个人主页。设计、素材提示词和局部验证见[活动页说明](docs/activity/QA.md)。活动页现已授权发布到生产环境，素材使用内容版本路径以避开旧字体长缓存，见[生产发布记录](../../docs/ACTIVITY-MONITOR-RELEASE-20261029.md)。

真理之塔是游戏虚构探索信标，无实体塔楼；其打卡按现有地图标记位置的35米范围判定，不绕过定位。地标保留组员预置校园 UV；设备位置由浏览器 WGS84 定位经指定 v0.4 模型映射到画布。当前支持定位、朝向和距离打卡，也保留可选账号与云端游戏进度；未接入相机上传、完整多人玩法或实名身份验证。实时 GPS 仅用于当前页面显示与范围判断，不写入本地或云端存档；此游戏功能不构成正式考勤或防作弊认证。

## 开发验收入口

仅开发服务支持以下固定预设，跳过入场与音频，并隔离普通用户存档：

| 地址 | 初始状态 |
| --- | --- |
| `/?qa=1&preset=fog` | 全部未打卡，探索度0% |
| `/?qa=1&preset=explored` | 除国防教育主题公园外的 7 处已发现，探索度 37% |

开发模式且带 `qa=1` 时，`window.__LIYUN__` 提供 `getState`、`getCamera`、`select`、`discover`、`setCamera`、`setPreset`、`showPanel`、`setEntered`、`reset`、`freeze`。在发现事件进行时调用 `freeze(1600)`，可固定到该事件开始后 1600 毫秒；`freeze()` 恢复。仅使用 `qa=1` 而没有固定 `preset` 时，仍会读写普通存档。生产构建不开放该调试接口。

上述命令与入口用于复核，不代表已经完成全部浏览器、设备或性能验收。最终实际测试范围以交付验收记录为准。
