# 场景与交互约定

此文档记录当前源码行为，供后续接入内容与复核使用。美术意图见 `creative-brief.md`，概览参数见 `scene-plan.json`；发生时序差异时，以 `src/effects/timing.ts` 和 `src/App.tsx` 的实现为准。

## 视觉与构图

二次元新国风赛璐璐剪纸是本版的主风格：深玉绿 `#193c37`、奶油色 `#f6eaca`、金色 `#d4b874`、银杏黄 `#cba84e`，使用清晰轮廓、平涂色块和分级明暗。地图建筑、道路与湖岸保持原有几何；树冠、云片、松枝、山石和细金线构成装饰层。

桌面左侧约五分之一承载五个剧情入口，标识位于左上，资源条位于右上，工具位于左下，校区与进度位于右下。中央区域用于地图观察与手势。移动横屏缩小标识、图标和资源条，隐藏菜单副标题，导航点击目标保持至少 44px 高。竖屏展示旋转引导，HUD 设为 `inert`，同时保留当前探索状态和此前横屏视角。

首次入口显示小型中央卡片，使用真实地图作为压暗背景。点击后移除入口遮罩并启动本次音乐。触控设备同时尝试浏览器全屏与横屏锁定，失败不会阻断探索。

## 地图与相机

世界逻辑尺寸始终为 4000×4958，地图 ID 为 `campus-v04-eaa124716c51375f`。所有地标、玩家与发现事件使用完整画布的 `{u,v}`；相机为 `{scale,x,y}`。完整换算公式与素材版本见 [ASSETS.md](ASSETS.md)。

初始视角以文萃楼实际地图坐标为锚点，将其放在视口宽度 61%、高度 58% 的位置。基础比例为：

```text
base = max(viewport.height / 1080 × 0.61,
           viewport.width / 1920 × 0.55,
           0.04)
minScale = base × 0.55
maxScale = base × 2.7
```

拖动限制在完整地图边界内；地图某一轴小于视口时沿该轴居中。滚轮和双指以手势中心下的世界点为缩放锚点；双击放大 1.45 倍。超过 5px 的移动会进入拖动，并短暂抑制地标点击，避免拖动结束误开详情。

手势层通过 `gestureCamera` 缓存最新请求的相机值。双指切回单指时以该值重建手势基线，避免快速抬起第二根手指时读到 React 尚未提交的旧一帧相机，造成视野跳变。

横屏尺寸变化时保留此前视口中心对应的 UV 并调整比例，再约束到地图边界。切换到竖屏时保存横屏相机，返回横屏后据此恢复。回中按钮恢复默认校园构图。探索目标位于主要可见区域外时，相机在约 650ms 内移向目标；减少动态时直接切换。相机位置不写入存档。

## 发现事件与存档

完整流程为：点击地标 → 详情面板 → 前往探索 → 更新发现状态与玩家目标 → 播放行进和点亮 → 回归环境微动。

`explore(state,id)` 在视觉序列开始前更新 `discoveredIds`、`unlockedRegionIds` 和 `playerUV`。重复发现同一 ID 返回原状态，未知 ID 不生效；进度由当前已发现地标的权重计算。刷新或中断动画后，已提交的发现结果仍然保留。

正常发现事件持续 3200ms，使用 `performance.now()` 时间轴而非累计帧数：

连续切换探索目标时，从已绘制的玩家位置和相机衔接下一段行进，并取消旧镜头的跟随。该呈现快照通过地图的 `onVisualPosition` 回调写入引用，不修改存档；玩家位置与地图变换在布局阶段同步，Canvas 仍只负责绘制。

| 归一化阶段 | 当前实现 |
| --- | --- |
| 0–0.43 | 玩家沿起点到目标插值移动；路径逐渐延伸 |
| 0.39–0.90 | 目标区域云层逐渐擦除 |
| 0.43–1.00 | 环形流光与星芒扩散、消退 |
| 结束 | 清除事件对象，保留发现状态与目标位置 |

减少动态设置将事件缩短为 400ms，玩家直接到达，保留轻量反馈并减少镜头运动。状态提交和进度逻辑一致。

真理之塔点亮后保留其 SVG 塔体结构；未解锁时的信标光效与已发现状态分开控制，解锁不会移除塔的地图形象。

存档键为 `liyun.exploration.v1`，结构为版本 1 的 `ExplorationState`：

```text
version
discoveredIds[]
unlockedRegionIds[]
playerUV { u, v }
settings { music, volume, quality, reducedMotion, track }
```

恢复时过滤未知 ID、去重，确保起点文萃楼存在；区域解锁从已知地标重新派生。音量限制在 0–1，曲目限制在 0–2，玩家 UV 要求为 0–1 内有限数。损坏 JSON 或不支持的版本回退到初始状态。存储不可用时继续使用内存状态。重置进度保留当前设置。

## 环境效果与声音

云片由固定随机种子生成并缓存；已发现地标周围通过同一相机下的区域擦除显露地图。默认种子为应用传入的 42。云层以 30fps 绘制；桌面高画质光效目标为 60fps，低画质或短屏为 30fps。高画质桌面像素密度为 1.5，移动或低画质为 1。此处为代码配置，不是设备实测帧率。

低画质或移动屏减少落叶和微光数量；减少动态时保留静态云图，停止环境落叶、微光与信标轨道运动。标签页隐藏或进入竖屏后停止持续绘制，恢复可见横屏后再继续。时间轴仍基于绝对时间，暂停期间已经结束的事件会收敛到完成状态。

页面入场从三首 BGM 中随机选择一首。单个音乐元素负责循环、切曲和淡入；设置改变会更新音量或停止播放。页面隐藏时暂停音乐并挂起提示音上下文，恢复可见后按原播放状态尝试恢复。音频策略拒绝时设置面板会提示重试；浏览器具体授权行为需要实际设备验证。

## 固定预设与验收接口

以下入口仅在 Vite 开发环境启用：

| 入口 | 状态与持久化 |
| --- | --- |
| `?qa=1&preset=fog` | 初始文萃楼，3%，不读写普通存档 |
| `?qa=1&preset=explored` | 前 7 个地标，37%，不读写普通存档 |
| `?qa=1` | 跳过入口和音频，但仍使用普通存档 |

`window.__LIYUN__` 的只读查询为 `getState()`、`getCamera()`；操作接口包括 `select(id)`、`discover(id)`、`showPanel(id)`、`setCamera(camera)`、`setPreset(name)`、`setEntered(boolean)`、`reset()`。调用 `freeze(offsetMs)` 可将特效与玩家动画固定到当前事件开始后的偏移时刻，`freeze()` 恢复；无事件时偏移按时间轴零点计算。使用固定预设完成自动验收，避免污染正常探索记录。

`setPreset(name)` 同时清除进行中的事件、冻结时刻、提示及其定时器、选中地标与打开的面板，并将相机恢复为当前视口的初始构图，使连续预设截图从一致状态开始。

`geometry.test.ts` 覆盖目标尺寸的 UV 往返、缩放锚点与边界；`state.test.ts` 覆盖 3%/37%、重复发现和存档恢复；`timing.test.ts` 覆盖云层时序、跳帧后的终态与随机种子。此处说明测试范围，不声明本次执行结果；浏览器截图、手势和设备验证另记。

## 后续内容与边界

首版 `LANDMARKS` 有 8 项，全部权重合计 45%。HUD「收录 /36」是完整游戏设计的 Mock 总数；体力、同行人数与章节编号同样为演示内容。当前实现不扣体力，不发起多人连接。继续扩充时应同时更新地标内容、图鉴、探索权重和文案。

地图和前景均由同一场景承载，未来加入任务、对话或联机时继续使用共享 UV 与显式事件。真实 GPS、经纬度映射、用户账户、服务端存档、完整活动日历和多人协作均属于后续接入范围。本地版本没有部署步骤或线上服务凭据。
