# 场景与交互约定

更新于2026-11-03，记录当前源码契约。本轮本地验收已收口，细分证据和队员后续真机/现场事项见[QA.md](QA.md)；历史方案见[UI-REFACTOR-PLAN-V2.md](UI-REFACTOR-PLAN-V2.md)。渲染参数与时长不是手机性能或现场定位结论。

## 坐标、内容与职责

逻辑画布固定为 **4000×4958**，`map_id = campus-v04-eaa124716c51375f`。地图、地标、玩家动画和区域轮廓共享完整图幅 `{u,v}`；相机为 `{scale,x,y}`。底图与定位 SDK / 模型保持冻结，来源和换算见 [ASSETS.md](ASSETS.md)。

`App.tsx` 负责装配，`useExplorerController` 组合数据、会话、路由、地图和发现动作。`useExploration` 保存持久探索，`useSettings` 保存偏好并解析实际画质，`useUi` 保存页面 / 选中目标和播报，`useCinematic` 保存演出队列。地图相机、实时 GPS / 精度 / 朝向、草稿手势与绘制快照不写入探索存档。

`src/data.ts` 的公共地标 UV 不因分区或打卡中心调整而移动。明确应用的确认覆盖通过 `DISPLAY_LANDMARKS / displayPlayerUV` 投射显示，打卡使用确认 WGS84 / 半径；持久化玩家锚点仍为共享白名单中的公开固定点。推荐草稿不启用覆盖。

## 地图与相机

默认构图仍以公共校园参考点和共享画幅为基础：

```text
base = max(viewport.height / 1080 × 0.61,
           viewport.width / 1920 × 0.55, 0.04)
minScale = base × 0.55
maxScale = base × settings.zoomLimit
```

缩放上限默认 2.7，可设 1.5–4；双击倍率默认 1.45，可选 1.2 / 1.45 / 1.8；拖动灵敏度默认 1，可设 0.6–2。滚轮与双指以手势中心的世界点为锚；拖动超过 5px 才进入拖动并短暂抑制误点击。`gestureCamera` 保存最新请求值，双指转单指时重建基线，避免读取旧 React 帧。

地图小于视口的轴居中，其他轴受完整图幅边界约束。横屏变化保留视口中心 UV；竖屏前保存横屏相机，恢复时回到该构图。回中在有新鲜图幅内设备位置时跟随实际位置，否则用默认构图；相机不持久化。定位授权、方向补偿与异常见 [REAL-LOCATION.md](REAL-LOCATION.md)。

## 分区与团队标定

`src/content/regions.json` 定义游戏外边界、8 个分区、解锁关联、顺序、故事和插画。当前为 recommended 推荐初稿，没有现场确认；`support_polygon_uv` 仅是定位采样覆盖，不能替代游戏边界或行政校界。推荐几何支持凹多边形并覆盖原锚点，但结构校验不构成现场确认。

区域持久化状态来自独立 `unlockedRegionIds`。合法 v2 / v3 记录保留这个集合，不再从 `discoveredIds` 强制重算。正常发现将相关新区域加入集合；区域边缘和解锁状态不由环境云雾替代。

`world/fog/RegionVeil`随同一相机变换绘制不透明纸底、墨纹、边缘和未启印章，位于地标层下。当前locked分区先合成一个同向nonzero纸底path，再绘各区，消除两个独立抗锯齿边相接时约1px透底；解锁时只移除对应纸底子路径，原piece继续墨散。`maskImage`可选，polygon为几何兜底。高/极致优先ImageGen云纹，底下是真实SVG程序云纹备用，纹理缺失仍可呈现；低档纯纸。`inkLayers`控制层数，`inkRevealFidelity`控制墨散细节。GSAP完成后卸载；低档/减少闪光淡出，减少动态立即收敛。八区24内部点、13共享边界、相邻解锁/重锁与相机对齐的[103项有限像素验证](../../../qa/ui-implementation-20261103/world-cinematic/final/region-pixels/README.md)已通过，不是任意区域重叠或所有像素的穷举。

团队仅在本地开发服务通过[`?tool=calibration`](http://127.0.0.1:5174/?tool=calibration)或`/calibrate.html`整理候选。编辑器和包装页不进入生产包，正式设置隐藏作者入口；生产误入工具URL仅显示本地说明且保持隔离。工具不自动取GPS，草稿独立。现场确认、dry-run、显式`--apply`见[作者指南](../src/calibration/AUTHORING.md)。默认打卡覆盖关闭且为空，确认应用前不改变实际打卡。

## 发现、前奏与演出

流程为：点击地标 → 查看资格 → 有效位置到达 → 确认打卡 → 状态先提交 → 地图前奏 → 依次呈现演出 → 用户继续 → 地图。位置校验要求 WGS84、15 秒新鲜度、50 米精度门槛和有效半径；未知 ID、重复发现或不合格位置返回原状态。位置条件不是服务器防作弊证明。

正常前奏 3200ms，减少动态 400ms，使用 `performance.now()`。正常阶段中，0–0.43 为行进，0.39–0.90 为局部环境雾退去，0.43–1.00 为环光；这套反馈和独立区域遮罩分别存在。连续目标从已绘制快照续接，快照不写存档。发现终态已经提交，刷新或跳过不会撤销进度。

演出 payload 区分 `landmark / region`，具有内容 ID、进度增量、可呈现时间及 quick 标记。主视觉时间轴为正常 **5.2 秒**、减少动态 **1 秒**、连续发现快版 **2.4 秒**。到达末帧后保留故事供阅读，等待“继续探索”、任意点击、Escape 或 Space；不会由时长自动关页。关闭演出设置清空呈现队列，已提交探索保留。

有图时读取 `/assets/landmarks/<id>/hero.webp` 等内容配置，明确标为概念占位；失败时用程序化剪纸山水兜底，不阻断进程。8 张生成的地标主插画不是校园实景照片，来源见 [ASSETS.md](ASSETS.md)。

Framer 负责 UI / Modal 的进入、布局与退出，GSAP 负责墨散和演出内部可清理时间轴；p5 / Canvas 负责高频绘制。禁止两引擎同时写同一元素的 transform。

## 画质、队列与声音

`QualitySpec` 统一提供像素密度、云雾 / 光效帧率、落叶 / 微光数量、云纹层数、模糊、墨散保真、环境装饰、阴影和光晕。低 / 高 / 极致的基底和覆盖分别保存；单项自定义不会静默回到 high。系统与游戏减少动态取或，模糊、环境和强闪光按全局信号收敛，HUD 缩放为 0.9 / 1 / 1.12。

自动降级只采样未暂停的 high / ultra：首窗 5 秒，之后 30 秒，连续两个窗口低于 26fps 才降一档；暂停 / 隐藏丢弃窗口和连续计数。关闭后移除采样，不自动恢复；多次降级保留最初来源供手动恢复，一段经历只播报一次。代码配置不能作为真机 FPS 证据。

播报为 FIFO，每条保存自己的 duration；页面遮挡时保留队首，恢复后重新给它停留时间。演出另有 FIFO，不以一条 toast 替代完整队列。

入场手势启动单个循环音乐元素，负责切曲、淡入和音量；界面反馈与解锁音遵循 `uiSound` 和声音音量。隐藏时暂停音乐 / 音频上下文，可见后按原状态尝试恢复。真实设备授权和听音不由桌面自动化证明。

## 存档、数据操作与 DEVQA

键名仍为 `liyun.exploration.v2`，结构输出 v3：`version / discoveredIds / unlockedRegionIds / playerUV / settings`。未知 ID 清洗并去重，玩家值只保留白名单公开锚点；合法独立区域集合保留。v1 演示只迁移设置，不能变成真实打卡；v2 合法进度增量迁移。会话、实时位置和相机不进入此快照，完整规则见 [ACCOUNT.md](ACCOUNT.md)。

重置清空探索并保留设置，登录时串行写回空状态；清本机移除本地探索和会话、回入口且不删云端；导出清洗当前内存快照，不依赖旧 localStorage 键。三个操作通过 App 回调执行；重置 / 清本机 / 恢复默认分别确认。云端首次读取失败时阻止旧本机状态自动 PUT，先重试读取。

开发环境 `qa=1` 下的所有模式均隔离普通存档和真实账号；fog 为 0%，explored 为 7 地标 / 37%。`?tool=calibration` 独立运行也隔离普通存储；不带 qa 参数时不提供调试桥。生产构建不提供 `window.__LIYUN__`。

查询：`getState / getCamera / getEvent / getUi / getRegions`。操作：`select / discover / showPanel / setRoute / setCamera / setPreset / setEntered / reset / freeze / setSettings / setQualityPreset / unlockRegion / previewCinematic`。例如 `unlockRegion('beihu', false)` 验证独立锁定，`previewCinematic('region', 'beihu')` 验证区域演出；`discover` 仍执行定位条件。`freeze(offsetMs)` 控制地图发现事件，不是演出自动退出定时器。

当前 8 地标全部权重合计 45%；界面收录总数来自真实数组，不使用旧 `/36`、体力或在线人数 Mock。多人协作、相机上传和正式身份核验仍不在当前能力范围。所有自动化、现场与发布证明范围分别记入 [QA.md](QA.md)。
