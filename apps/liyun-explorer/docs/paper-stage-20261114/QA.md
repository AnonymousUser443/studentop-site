# 一纸见校园 · 本地验收

本轮改动仅涉及理韵寻踪玩家端。实际复核使用 Chromium、独立本机预览与临时 SQLite；账号、地点与解锁结果均为验收用例，不连接生产服务。

| 场景 | 实际经过 |
| --- | --- |
| 静止地图 | 锁区显示同一张生成的低对比纹理。静止期没有雾画布、云纹层、遮罩动画或宣纸 Canvas；既有落叶和光效可独立运行。 |
| 连续解锁 | 北湖与图书馆的局部燃蚀重叠，随后重新锁定图书馆，立即恢复其完整宣纸。结束后无残留燃蚀画布。减少动态模式即时揭景。 |
| 账号回归 | 清掉本地进度后，以临时库已有两处进度的账号进场。入场窗收卷前两处仍被遮住，随后北湖和图书馆分别进入 `arrival` 揭景，并在约 1.8 秒的取样时彻底退出；其他六个分区继续覆盖。 |
| 首开与活动详情 | 首次点击菜单没有全屏加载状态。活动首次直接进入 `opening`、画面为 `ready`；切换四季主题后仍能直接呈现。图鉴不出现加载占位。 |
| 667 × 375 横屏 | 菜单实际宽 314px，右边地图保留 353px，测得主要触控区最小 44 × 44px，菜单内容无横向溢出。桌面保持原有宽度策略。此项为浏览器小视口测试。 |
| 图鉴与确认 | 图鉴出现时展开纸面，图标与文字错拍；关闭先收扁，再坠落并卸载，原按钮重新获焦。快速回开通过。设置确认弹层退出期间 Radix 仍持有焦点，拦截重复 Escape 和 Tab；抽帧测到整卷离开屏底，随后焦点回到原设置按钮。 |

本地构建、前端 176 项、账号数据层及 HTTP 19 项、资源哈希和地图标定检查均通过。未进行实体手机帧率测量，不能按这些结果推断平均帧率提升。

从项目目录运行 `npm ci`，再运行 `node scripts/paper-stage-preview.mjs`，可在 <http://127.0.0.1:5224/?qa=1&preset=explored> 查看示例进度揭景。普通路径可操作临时账号，手机尺寸示例由 `/__paper-qa-phone` 提供。实际截图保存在制作工作区的验收副本中。
