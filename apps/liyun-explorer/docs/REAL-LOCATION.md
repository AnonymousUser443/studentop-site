## 状态和交互

- 未主动开启定位时不请求权限，不显示预置位置或存档位置冒充实际蓝点。
- 点击「定位到我」时，同步调用方向授权接口后启动 GPS，不增加第二个朝向按钮或应用内确认框。方向授权必须位于点击事件调用栈中，不能放在定位成功回调之后。只调用 `DeviceOrientationEvent.requestPermission(true)`，不额外申请 `DeviceMotionEvent` 权限。同一页面已获方向授权时缓存结果，回中/停止后恢复不重复调用方向授权接口；刷新或换站点后的授权持久性由浏览器决定。
- 定位和方向是浏览器分别管理的能力：一次点击不等于强制只有一个系统授权框。首次或授权被清除后，浏览器可能分别询问两项权限。网页不能代替用户授权、跳过系统提示或保证强制合并。
- 方向拒绝、无设备支持或无有效传感器数据时，显示原因并保留正常定位。需要重试时仍使用同一个定位按钮。
- 开启后高精度持续定位，禁止缓存，超时15秒；允许停止或显式重试。
- 蓝点与解锁动画完全分离。确认范围打卡后不会把实际设备位置移到目标。
- 拖动/缩放地图取消自动跟随，蓝点仍更新；点击定位按钮重新跟随。图幅边界仍受原相机限制，不挪动真实坐标来迎合构图。
- 显示设备报告的精度与近似范围；大于50米时灰显并提示精度不足，不显示看似精确的点位距离。此50米为位置展示质量门槛，不是修改拍照打卡规则。
- 超过15秒无新位置时标记「上次位置」并停止使用它计算距离。过期、无效或乱序回调不会覆盖新位置。
- 超出完整地图画布时明确反馈，不把 GPS 硬夹到地图边缘；这不等同于已经实现校园多边形围栏。
- 映射处于控制点范围外的 transition / extrapolated 区域时显示外推提示。原模型留一 RMSE 约5.43米属于同批数据交叉验证，不是全校园独立实测保证；当前设备 accuracy 也不等于实测真值。
- 页面切到后台或 pagehide 时停止监听；回前台需主动继续。停止、重试、卸载后忽略旧回调。
- 实时位置只存在内存，不写入 `localStorage`、不发往后端。原探索进度仍按旧方式本地保存。
- 朝向采用 Safari 的指南针读数或 Android 的绝对方向事件，不用相对 alpha 或 GPS 移动方向冒充指南针。以屏幕上边缘为方向，补偿左右横屏和倾斜；接近垂直、投影不可靠时提示稍微放平手机。读数属于指南针参考，可能受磁场干扰，不承诺绝对真北精度。
- 扇形方向通过原 v0.4 模型把10米方向向量投影到完整画布，保留地图局部缩放和倾斜关系，不改模型参数。定位超过15秒、定位误差大于50米、方向超过3秒无有效数据、指南针精度不足时隐藏扇形；不会冻结旧角度冒充实时朝向。停止、切后台和卸载会清除方向事件监听与定时器，返回后需主动继续。

原界面的竖屏引导与横屏布局继续沿用。本次未承担 FE-04 的完整竖屏/平板重排；手机验证使用横屏。已新增朝向传感器与基于实际位置的打卡，AR、路线规划与 FE-02 的真实拍照上传仍不属于本次改动。距离打卡不能作为图片上传或后端记录保存的证据。
