# 活动一览 · 开发简报

基线：团队 PR #7 合并后的 `230f80d`。用户提供的《理韵寻踪》活动页面动效设计与实施规范及同包概念图作为视觉与交互参考，地图批注要求移除大条幅和体力界面，以原探索指引的位置作为活动入口。保留团队最新的地图标定、纸浪背景、雾效、点亮声音、个人主页及账号能力。

## 体验与角色

1. 玩家经历：从熟悉的校园地图，展开一本能翻阅校园时令故事的长卷。
2. 玩家角色：记录风景的校园寻访者，活动未开放时先翻阅预告，不凭界面获得虚构进度。
3. 入境动作：地图轻暗、中央画卷浮现、左侧悬挂卷轴下展，信息和主动作依次就位。
4. 关键转折：稳定的目录书签移位后，湖光、银杏和纸上标题更换篇章；进入地图预览后，真实地图承接操作，并可回到原先所选篇章。

## 艺术方向

沿用青绿、月白宣纸、暖金银杏。左卷轴、中央湖景、右纸面形成可辨层次，上下保持柔焦留白。信息和按钮使用真实 DOM，画面素材不含可交互文字，不铺整张设计稿。标题优先沿用现有已授权书法字体，正文沿用本地阅读字体。

方向比较：普通活动卡片不能表达设计图的长卷结构；全屏粒子场会压过目录与文案。本轮选用悬挂卷轴与局部插画微动，以读、选、返回的连续性为主。

## 节奏与边界

引入 0–140ms 地图收暗；探索 100–450ms 中央画卷显现；变化 170–560ms 卷轴展开；蓄势 350–740ms 场景和标题错峰；释放 610–950ms 奖励示意和动作就绪；余韵仅保留少量非同步银杏叶和湖面光斑。切章快于首次开页，关闭与返回可中断。减少动态、低画质、后台均有降级。

不新增自动配乐或外部音源，继续由现有校园配乐设置控制声音。活动预告与奖励示意不冒充已上线活动、已发奖励或历史成果。GPS、朝向和账号令牌不进入活动配置或新存档。当前不改后端活动授权协议，不发布到树莓派。

## 验收范围

桌面 1920×1080、1366×768，横屏 915×412、844×390，补查极矮横屏和竖屏引导。覆盖五个主题、快速切换、奖励说明、预告/地图预览/个人回顾、返回、关闭、焦点、触屏、减少动态、图片失败与反复开关。保留真实浏览器截图和局部检查结果，不沿用历史通过数。
