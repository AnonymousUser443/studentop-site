# 理韵寻踪 · 性能复核（2026-11-15）

审查范围：首屏和发布包、地图及环境画布、宣纸进入与打卡、信笺 / 活动 / 菜单 / 设置、登录与云存档。三路并行修改，集成时保留校准图、区域几何、纸纹水印、逐字与套方纹时序、设置连续烟迹及偏好行为。本轮只改本地代码。

## 修复与覆盖

- **地图**：指针移动一帧提交一次，缩放和剩余单指接力保留输入锚点。相机只通知地图和氛围层，分离 HUD 和菜单。标签避让仅在字号、节点、画幅等确实变化时重新测量，平移用预先算好的矩形。
- **光效与宣纸**：原生 Canvas 2D 替代完整 p5 运行时。叶片和微光预绘成小图，保留尺寸、透明度、轨迹和预设帧率；离屏和暂停状态不持续绘制。极端分辨率限制氛围层像素缓冲，不限制地图的精度。烧灼噪场复用网格和三角函数结果；宣纸仍预烘，离屏的临时揭纸停画后沿现有时间轴继续。
- **启动与缓存**：独立的发布内容、不可变包、SW 注册同时开始，首个活动的插画预热，后续插画闲时逐张解码。热启动仍做 SHA-256 校验，仅写入新资源和修复项。旧离线壳在新包验完前继续可用；带私有缓存响应头的工坊图片不读取旧缓存，也不进入新缓存。已有完整缓存时断网可进入并读取音频范围。
- **界面**：活动关闭后卸载内容且保留章节与滚位，换章复用图片节点，双层矩形平移完成揭图。信笺内文字与套方纹按原时间错峰，快速关窗从当前状态退出。画质滑条拖动期间只更新自身，松手或键盘确认才改变全局参数。恭喜数字只更新自身文本。
- **账号**：保持原密码推导和 SQLite 权限；在工作线程池异步计算，提交前再核对凭据。单账号一次登录，最多两路并行计算与 24 个排队，正在读写存档的会话不会被密码计算堵住。

## 复现

- `npm run build`、`npm run verify:map`、`npm test`。校准核验检查 6 份资产的哈希，4000 × 4958、WGS84。
- 仓库根执行 `node --test qa/liyun-cache-worker-tests.mjs qa/liyun-release-tests.mjs`。
- 应用目录执行 `node --test server/store.test.mjs server/server.test.mjs server/published-content.test.mjs server/authoring.test.mjs server/author-http.test.mjs`。
- 准备两份本机不可变发布目录；在应用目录依次跑 `node scripts/browser-performance-qa.mjs <发布目录> <输出.json>`。使用 Edge、`LIYUN_QA_RUNS=3`、`LIYUN_QA_CPU=4`，手机横屏 667 × 375。每轮使用新浏览器上下文，测试首次、热缓存、断网入场和音频 Range；拖图录制 1.8 秒，每帧合成 8 个移动事件。
- `node scripts/browser-motion-qa.mjs` 检查宣纸入场、信笺开合、设置动效与焦点，支持 `LIYUN_QA_DIST`、`LIYUN_QA_PHONE`、`LIYUN_QA_REDUCED`。定位验证用 `node scripts/browser-location-qa.mjs`（模拟坐标）。
- `node scripts/server-performance-qa.mjs` 使用假账号、临时库和回环端口，重复 5 轮四路同时登录与六次存档查询。

浏览器结果是在本机用软件模拟 CPU、屏幕和地理位置，未作为低端手机、微信或树莓派的实机数据。
