# 侧边山水位图（可选）

把生成好的竖幅山水放进这个文件夹，界面会自动用它覆盖矢量版；缺文件或加载失败时自动退回矢量版。

| 文件名 | 位置 |
| --- | --- |
| `side-left.webp` | 左侧带（贴屏幕左边） |
| `side-right.webp` | 右侧带（贴屏幕右边） |

- 格式：优先 `.webp`，也支持 `.png` / `.jpg`
- 建议尺寸：**竖幅 1:4 左右**（例如 720×2880 或 900×3600），场景要贴外边缘、内侧留空，方便蒙版化开
- 底色：奶油纸色 `#f6efd8` 或透明均可
- 建议不超过 800KB，可用 squoosh 压一下
