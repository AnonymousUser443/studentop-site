# 理韵墨苑

理韵文化协会活动室的独立三维观览应用。以用户提供的六页活动室照片为依据，用细体素重建月洞格栅、博古架、课桌折椅、白柜、窗间琴拓与紫幕讲堂。参考逐页说明、比例推断与纹样重绘范围见 [REFERENCE.md](REFERENCE.md)。

应用采用 Three.js 与 Vite，依赖和锁文件独立于其他应用。Win Web 桌面快捷方式打开独立页面。

2026-11-01已发布至 <https://studentop.cn:14355/liyun-moyuan/>，桌面、开始菜单和项目索引入口同步上线。生产收据、验证范围与回滚目标见[发布记录](../../docs/MOYUAN-RELEASE-20261101.md)。

## 本地运行

从仓库根目录执行，使用 Node.js 22.12+，推荐 Node.js 24：

```powershell
npm --prefix apps/liyun-moyuan ci
npm --prefix apps/liyun-moyuan run dev
```

开发地址为 `http://127.0.0.1:5181/`。该端口使用 strictPort，端口已占用时直接报错。也可从仓库根运行统一启动器 `node tools/dev-workspace.mjs`，由它管理本应用；不要同时运行第二个占用同一端口的实例。

构建与本地预览：

```powershell
npm --prefix apps/liyun-moyuan run build
npm --prefix apps/liyun-moyuan run preview
```

构建输出到本应用的 `dist/`，公开路径基址为 `/liyun-moyuan/`。预览端口为 `4181`，访问 `http://127.0.0.1:4181/liyun-moyuan/`。构建文件中的脚本、样式及字体路径应保留这个前缀；构建与预览命令本身不发布到生产服务器。

## 观览方式

下方提供五个预设位置，切换时相机平滑移动；系统开启减少动态效果时直接到达对应位置。

| 位置 | 观览内容 |
| --- | --- |
| 全景模型 | 剖开墙顶观察完整布局和课桌区 |
| 一室风雅 | 从房间内部看月洞、课桌和两侧陈设 |
| 月洞茶席 | 近看圆形木格、博古架、青花与茶椅 |
| 临窗书案 | 观察书案、琴拓与窗侧光线 |
| 帷幕讲堂 | 朝向紫色帷幕和移动屏幕 |

鼠标左键拖动环顾，滚轮调整远近，右键拖动平移。触屏可单指环顾、双指缩放或平移。选择新的位置会结束自动环顾。

右侧工具分别切换日光/夜读、自动环顾、精细光影和全屏。“精细”开关控制环境遮蔽、泛光、光束与微尘；切换为清晰模式后保留模型和基础光照。右上“复原手记”说明空间、材料及复原限制，Escape 可关闭手记。支持的浏览器可进入全屏；全屏能力由浏览器决定。

## 材质与渲染

渲染默认优先表现材质与空间：世界坐标木纹和纤维 Shader、物理釉面与金属、柔和阴影、环境遮蔽、低强度 Bloom、窗侧光束、微尘和轻微调色。家具与器物保留细小阶梯轮廓，重复体素按材质批量实例化，避免给每一小块创建独立绘制对象。

需要支持 WebGL 2 的浏览器。没有将手机屏幕宽度作为降低模型精度的条件；仍会受到设备显存、GPU 和浏览器上下文限制。场景在切到后台时暂停绘制，图形上下文丢失时提供重新进入入口。

字体随应用打包，Noto 字体的 OFL 许可保存在 `public/fonts/`；Vite 构建使用 `src/assets/fonts/` 中与 public 字节一致的副本，并由 `tools/build-fonts.py` 同步生成。琴拓与青花纹样为程序重绘，不使用人物照片作贴图。

## 复原范围

房间和家具尺寸按照片比例估算，遮挡与照片未覆盖处根据相邻结构补全。数字场景并非测量扫描，不能作为精确的建筑尺寸或现场器物数量记录。人物不进入场景，不可读的题字和细纹以示意重绘；详见参考手记。
