# 云上良乡 · 校园地标参考

调研日期：2026-10-28。用于以北理工良乡校区为主题的 Three.js 体素幻想场景。以下区分校园事实与艺术化建模建议；浮岛、云海、金边道路属于创作设定，不代表校园真实空间关系。

## 优先地标

### 1. 徐特立图书馆 / `library`

- 校园事实：学校良乡校区图书馆名为“徐特立图书馆”，不是中关村馆。校方报道直接写明这一点。
- 外观方向：灰白石材立面，左右翼楼与中间高大的青蓝玻璃幕墙入口；玻璃门厅上方红色中文馆名，入口前宽石阶。体素造型应保留横向体量和中间玻璃凹口，避免误画成中式红砖塔楼。
- 艺术化建议：浅灰和象牙白墙体、青灰玻璃窗网格、顶部横梁、低矮平台，红字“徐特立图书馆”；压缩楼层数量但保留入口识别特征。
- 官方依据：[2010级新同学走进图书馆开启快乐学习新航程](https://www.bit.edu.cn/xww/xwtt/a59063.htm)。
- 官方门厅照片：[北理工“首届图书馆文化节”在良乡校区成功举办](https://www.bit.edu.cn/xww/xwtt/a66529.htm)。
- 当期外观文字佐证：[北京理工大学徐特立图书馆：典籍承文脉 书香育英才](https://www.bjnews.com.cn/detail/1790059564189507.html)（2026-09，描述“灰白色外墙、透亮玻璃幕墙门廊”）。

### 2. 良乡校门 / `gate`

- 校园事实：良乡校区管理处官方风光图库设有“校门”专页，部门介绍页也使用了校门照片。
- 外观方向：现代浅灰石质门墩、横向铭牌、金色“北京理工大学”校名及校徽；宽道路、栅栏、路灯。它不应使用中关村老校门的红砖中式外形。
- 艺术化建议：做成宽门墩与横向石梁组成的现代门架，校名牌用金色，配置两盏暖白路灯。不将尚未核实的具体方位“东大门”写入产品。
- 官方依据：[校门](https://liangxiang.bit.edu.cn/gbxqgk/xqfg/b170028.htm)、[良乡校区管理处部门介绍](https://liangxiang.bit.edu.cn/jgsz/bmjs/index.htm)。
- 官方新闻照片佐证：[静待疫散花开，北理工良乡校区春季学期首日运行有条不紊](https://www.bit.edu.cn/xww/zhxw/yljs/a183674.htm)。
- 参考图片入口：[管理处校门照片](https://liangxiang.bit.edu.cn/mediaDir/images/content/2018-11/20181105080938766080.jpg)。

### 3. 北湖 / `lake`

- 校园事实：良乡校区有北湖，校方报道确认湖周的初心亭、功勋廊、延安石等自然人文景观；校方图库另有“北湖晴日”“北湖芦花”“北湖夕照”。不要将该湖命名为“镜湖”或“远志湖”。
- 艺术化建议：浅青水体、错落的石岸、低垂柳树、芦苇、荷叶和荷花，搭配湖畔小亭与短廊。亭的屋面形制不在已取得材料中细化确认，简化亭子是艺术处理。
- 官方依据：[北理工良乡校区北湖开工建设](https://www.bit.edu.cn/xww/xwtt/a49536.htm)、[北湖晴日](https://liangxiang.bit.edu.cn/gbxqgk/xqfg/b170048.htm)。
- 官方近况：[高质量发展成就巡礼之十一：北理工校园展现新图景](https://bit.edu.cn/xww/lgxb21/03ba20c7c0d54a1cb84ecce2da9b2443.htm)（2026-01-09）。

### 4. 文博中心 / `main`

- 校园事实：位于良乡校区，地上三层，包含博物馆、音乐厅、剧院。2023年亮相，学校2026年建设报道也确认已落成。不要与“文体中心”混为一体。
- 外观方向：宽阔低矮的浅色现代体量、庄重的连续柱廊；施工方明确记录室外大面积汉白玉柱与雕刻额坊。适合以成排暖白柱子、深色玻璃退界、宽檐口呈现。
- 艺术化建议：横向对称三层体量、8—10根方形白柱、深青灰窗面、浅金屋顶边缘。用方柱代替真实圆柱属于体素化。
- 校方依据：[北京理工大学良乡校区文博中心工程主体结构封顶](https://www.bit.edu.cn/xww/zhxw/xyjs/32e8e4598bf04cf6a18de64412be7488.htm)。
- 建造方一手资料与完工照片：[文化新地标闪耀亮相](https://www.bucg.com/xwxx/qydt/20231123/27344.shtml)。
- 房山区政府完工介绍：[北京理工大学良乡校区文博中心亮相良乡大学城](https://www.bjfsh.gov.cn/zhxw/bmdt/202311/t20231121_40068782.shtml)。

## 可扩展景观

### 5. 光明大道

- 校园事实：良乡校区官方图库列有“光明大道”。
- 艺术化建议：作为无尽道路的校园意象，用整齐银杏与石质灯柱组成轴线；悬浮和上升是幻想场景表达。
- 官方参考：[光明大道](https://liangxiang.bit.edu.cn/gbxqgk/xqfg/b170052.htm)、[官方校区风光第二页](https://liangxiang.bit.edu.cn/gbxqgk/xqfg/index1.htm)（包含“金秋银杏”等）。

### 6. 校训丰碑

- 校园事实：官方风光图库有“校训丰碑”专页。
- 艺术化建议：在图书馆或校门前放一块有阶梯底座的低矮碑石，以红色或金色字符呈现“德以明理 学以精工”。碑石具体形状与字符位置未经有效照片核验，按简化雕塑处理。
- 官方参考：[校训丰碑](https://liangxiang.bit.edu.cn/gbxqgk/xqfg/b170066.htm)。

## 研究限制与实现边界

- 2019年的管理处图库网页可访问，但部分旧图片指向 `/pub/lxxqglc/mediaDir/` 路径，现返回404。其名称可用于确认地标，不能据此声称复原了原照片的全部细节。
- 已使用官方新闻、管理处图库、施工方与政府完工资料交叉核对。网上检索可能混入中关村、珠海、北京工商大学等校区；不使用其中无法确认的红砖拱门、热带植物或钟楼作为良乡地标。
- 这是艺术化的校园体素印象，并非测绘模型或真实校园地图。建筑比例、摆放、浮岛基础和色彩可为构图服务。
- agent-reach 的 Exa 后端在本机未配置（`Unknown MCP server 'exa'`），资料检索改用可用的网页搜索工具，原始资料均使用明确链接保存。
