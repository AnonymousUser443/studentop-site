# 补充实拍的体素素材

依据本次提供的五张照片构建，建筑均为立方体实例组成的三维模型。照片本身没有作为建筑表面贴图，也不参与页面运行；题字平面使用字体生成，I ♥ BIT、校门竖排校名、红色「北理工」雕塑与展馆前景校名是实际的体素立体字。

新模型按照片外形命名；未把不确定的建筑用途或校区位置当作已核实信息。主楼、圆厅和展馆等名称在此用于区分体素素材。场景保留艺术化比例和浮岛布局。

素材使用 `createLandmark(id, { seed })` 创建，地面为 `y=0`、正面朝 `+z`，占地控制在 34×24 单位内。新素材代码位于 `src/photo-modern.js`、`src/photo-heritage.js`、`src/photo-gate.js`，公共题字、绿化和铺地工具位于 `src/photo-helpers.js`。

漫游已扩展为八组：徐特立图书馆、双塔校门、圆厅、翼形展馆、白石主楼、校训石、北湖与文博中心。左下方八个菱形可逐一跳转，悬停显示名称。固定八座地标岛循环使用，沿途不会不断创建更多建筑。
