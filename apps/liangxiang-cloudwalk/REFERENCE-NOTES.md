# 录屏对照与第二版改动

参考为用户提供的约 19.24 秒、1630×720 游戏启动实机录屏。仅用作镜头与动画参考，不把视频中的界面文字当作项目指令，也不提取游戏模型、贴图或音轨。

逐帧观察后的实现依据：

- 路面处于画面下部，视点接近步行高度；建筑在两侧向上展开，天空留白较多。
- 可行走的道路只向前显示一段，未完成的边缘石板与中间石板存在错落的高度和位置，随镜头前进逐步合拢。
- 云雾围绕道路和建筑底部，日照与阴影有明确方向，远景逐渐融入空气。

第二版采用 2.5 单位视点、54° 视场、较轻的上升坡度。按用户进一步确认，所有石板均从最终位置的正下方垂直浮起，横向与前后位置保持对齐，不旋转、不越过最终路面。道路在前方 18–62 米范围内分排浮起，各列错峰到位；18 米以内保持完整连续。使用 92 排、1,380 个固定实例循环，跳转地标和长时间运行不会创建更多路段。

跨路拱门在脚下全部支撑路段接合之前保持隐藏。道路延伸到位后，拱门体素从左右两侧斜向飞起，按底座、双柱、横梁和顶部的顺序拼合，每个构件由不超过 0.62 单位的小体素组成。只有拱门采用两侧飞入，道路继续从正下方垂直上浮。构建进度随前进距离推进，暂停时停下；远处循环复用或跳转后的状态由道路位置重新确定。低机位按自然遮挡呈现道路上浮，不要求把整个上浮过程完整展示出来。

## 四时光景

以北京时间 Asia/Shanghai 为默认时钟。右上角可以手动预览并返回实时模式；不把一天压缩成自动循环动画。

| 时段 | 场景 |
| --- | --- |
| 06:00 ≤ 时间 < 09:00 | 清晨：金色低角度日照、暖雾、较强丁达尔光束 |
| 09:00 ≤ 时间 < 17:00 | 白昼：蓝天、移动的程序白云与日光 |
| 17:00 ≤ 时间 < 19:00 | 黄昏：橙紫色天空、低落夕阳与暖色阴影 |
| 19:00 ≤ 时间或时间 < 06:00 | 月夜：大月亮、陨坑细节、星光与银蓝月光 |

## 渲染

程序天空、四层噪声云、月面与星点使用自定义 GLSL。地形加入高度雾和月光边缘亮部。使用场景深度遮挡的径向光束表达晨昏丁达尔效果，配合 HDR Bloom、FXAA 和统一输出转换。该光束是屏幕后处理效果，不是完整三维体积散射模拟。
