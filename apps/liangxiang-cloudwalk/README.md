# 云上良乡

> 已按源项目提交 `5c43b09` 的精确 39 文件清单导入本仓库。场景、BGM、字体与研究资料保留；集成差异、权利边界及校验清单见 [IMPORT-NOTES.md](./IMPORT-NOTES.md)。下方原项目的历史验证记录不等于本仓库已经复跑通过。

以北京理工大学校园为灵感的 Three.js 体素幻想漫游。镜头贴近暖白石阶，前方石板逐排从云海中浮起、拼合；八组校园地标位于道路两侧的浮岛，包含良乡主题建筑及依据补充实拍制作的主楼、圆厅、展馆和校训石。场景按北京时间切换清晨、白昼、黄昏和月夜。

## 运行

需要 Node.js 20.19+ 或 22.12+。

```sh
npm ci
npm run dev
```

本地开发固定为 `http://127.0.0.1:5180/`，预览固定为 `http://127.0.0.1:4180/`；均仅监听回环，端口占用直接失败，不自动换端口。生产构建使用 `npm run build`，保留 `base: './'`，目标为主域下的 `/voxel-campus/`；`dist/` 由统一部署流程处理。导入后的构建、浏览器与发布证据见[发布记录](../../docs/RELEASE-20261028.md)，团队日常操作见[贡献指南](../../CONTRIBUTING.md)。下方源项目历史记录保持原貌。

## 交互

- 打开后缓慢前行，点击「启程」进入漫游。
- `Space` 暂停/继续，`M` 环境音乐，`F` 全屏，`H` 隐藏/显示界面。
- 右下角切换三档速度；左下角八个菱形前往不同地标，悬停显示名称。
- 鼠标移动产生轻微视角变化。仅适配横屏，竖屏显示旋转提示并停止三维绘制。
- 点击「启程」开始播放当前时段的 BGM；右上角音乐按钮或 `M` 键开关，主动关闭后再次启程仍保持关闭。音乐循环播放，切换光景时用 2.4 秒淡入淡出衔接，暂停前行时音乐继续。
- 右上角的时钟可选择「跟随时间 / 清晨 / 白昼 / 黄昏 / 月夜」。默认跟随北京时间；清晨 06–09、白昼 09–17、黄昏 17–19、月夜 19–次日 06。手动预览不会修改系统时间。
- 也可用 `?time=morning`、`?time=day`、`?time=evening`、`?time=night` 直接打开某个光景。

## 实现

- Three.js + Vite，全部建筑、树木、道路和浮岛由程序生成，无运行时 CDN 依赖。
- `src/engine.js`：相机、光照、云海、道路与浮岛循环、粒子。
- `src/voxel.js`：同一网格的立方体实例合批。
- `src/road.js`：固定实例池的逐排铺路，石板从最终位置正下方垂直上升并接合。
- `src/portal.js`：道路完成脚下支撑后，拱门体素从左右两侧飞起，依次拼合底座、双柱、横梁和顶部；远处尚无道路的拱门隐藏。
- `src/atmosphere.js`：四时天空、程序云、太阳、月面、星空、灯光与雾色。
- `src/effects.js` / `src/cloud-sea.js`：深度遮挡光束、Bloom、FXAA 以及流动云海 Shader。
- `src/landmarks.js`：八组地标目录、素材创建入口与校园题字。
- `src/photo-modern.js` / `src/photo-heritage.js` / `src/photo-gate.js`：五张补充实拍对应的体素建筑、校训石和标志雕塑；来源与 ID 见 [PHOTO-ASSETS.md](./PHOTO-ASSETS.md)。
- `src/ui.js` / `src/style.css`：启动界面、说明与横屏适配。
- `src/audio.js`：按光景选择本地 BGM，以流式播放和 Web Audio 增益完成循环、淡入淡出与静音；仅加载播放过的曲目，最多复用三个播放器。
- 道路使用固定数量的区段循环，坐标相对于当前行程计算；不随行程增加模型或纹理数量。

## 场景音乐

音乐直接使用 `bgm/` 内提供的三个 Opus 文件，Vite 自动将它们打包到 `dist/assets/`，保留相对路径部署支持。进入页面时保持安静，用户点击「启程」、选择地标或主动开启音乐后播放；自动跟随北京时间和手动光景预览共用同一时段映射。

| 时段 | 音乐 |
| --- | --- |
| 清晨 06:00–09:00 | `bgm/dawn_dusk.opus` |
| 白昼 09:00–17:00 | `bgm/day.opus` |
| 黄昏 17:00–19:00 | `bgm/dawn_dusk.opus` |
| 月夜 19:00–次日 06:00 | `bgm/night.opus` |

清晨与黄昏共用同一首，直接切换这两个光景时音乐不中断、不从头重播。静音期间切换时段不会偷偷恢复音乐；快速切换时段时只保留最后一次选择。重新开启音乐会继续播放对应曲目。

2026-10-30 修正慢网下切换/静音未取消尚未就绪的旧曲目请求：实际释放网络读取，重选时复用播放器；已响起的音乐仍交叉淡化。浏览器稍后发出的206补段请求与首播等待需要分别判断，详见[本轮排查及21项音频回归](../../docs/VOXEL-AUDIO-20261030.md)。本次修复尚未重新部署；下方源项目历史记录不作为本轮证据。

## 验证（源项目历史记录）

以下通过描述来自源提交，原 `.preview/` 产物未导入，也未作为当前仓库通过证据。五个原验证脚本的固定机器路径已移除：可用 `PLAYWRIGHT_MODULE` 指向已有 Playwright，或从项目/仓库根模块解析；`BROWSER_EXECUTABLE` 可指定已安装浏览器，缺失时清楚报错，不自行安装。历史测试端口及部分 `.preview/` 夹具仍需独立准备；部分脚本会启动服务，仅由 Lead 在隔离验收窗口内决定是否执行。开发态仍有只读 `window.campus.stats()`，生产构建不再暴露该全局；旧 `check-bgm.mjs` 的生产段曾依赖它，当前生产验收应改用真实 UI、网络与音频观测，不能据旧脚本自动宣称生产通过。

独立浏览器验证脚本为 `scripts/verify.mjs`，检查路段循环、四时边界、光景切换和原有交互。测试截图和详细结果保存在 `.preview/`。第二版对照录屏的具体实现见 [REFERENCE-NOTES.md](./REFERENCE-NOTES.md)。

第二版生产构建与 39 项功能检查通过，四个时段均已独立渲染复核，无浏览器运行或 Shader 编译错误。最终截图脚本为 `scripts/snapshot.mjs`，其中另检查石板从下方单调上浮、保持水平位置与姿态、在 18 米处平滑接合。四时合图为 `.preview/four-times.png`，详细记录为 `.preview/verification.json` 与 `.preview/final-visuals.json`。

拱门构建另经 `node scripts/check-portal.mjs --browser` 验证：道路支撑未完成时隐藏，834 个体素从左右两侧飞入后精确归位，暂停、循环复用及跳转状态正确。道路正下方上浮的运动检查独立保留。构建阶段截图和记录位于 `.preview/portal-*.png` 与 `.preview/portal-verification.json`。

补充实拍素材通过 `node scripts/check-assets.mjs` 验证模型范围、五组参考造型、八组地标切换及小尺寸横屏布局；截图与报告位于 `.preview/asset-*.png` 与 `.preview/assets-verification.json`。

场景音乐使用 `node scripts/check-bgm.mjs` 验证真实 Opus 音频输出、文件末尾循环、四时映射、淡入淡出、静音保持、快速切换、播放失败后重试及生产包在子路径下的资源加载。报告位于 `.preview/bgm-verification.json`。

标题与界面打包了 Noto Serif SC / Noto Sans SC 的 WOFF2 字体子集，并保留系统字体回退。开源字体许可见 `public/fonts/OFL.txt`。校园名称与外形参考校方、建设单位资料，详细来源见 [RESEARCH.md](./RESEARCH.md)。比例、材质、亭子细节与空间布局经过艺术化调整；本作不是校园测绘模型，不使用原神的模型或贴图，音乐使用用户提供的 `bgm/` 文件。
