# 主应用存档与会话闭环 · 2026-11-03

最终结果：**37 / 37 项浏览器检查通过**。原始断言与请求顺序见 [results.json](results.json)，复跑入口为 [browser.cjs](browser.cjs)。

测试复用 `127.0.0.1:5176` 的开发前端，使用独立临时 Edge profile。所有 `/api/*` 请求经 CDP 拦截，转发到测试自己创建的随机回环端口、临时 SQLite 与合成账号；没有访问开发代理的既有账号服务或真实账号。脚本结束关闭自有浏览器、服务和数据库并移除自有临时目录。口令和 token 不写入证据文件。

## 已验证

- 固定 QA 预设初次加载不读取 / 写入普通探索键、旧探索键或会话键；重置、导出、清本机操作后三个普通键逐字节不变，无账号请求。
- `?tool=calibration` 不读取 / 写入普通键，不请求账号 API，也不暴露 `__LIYUN__`。普通开发页面同样没有 QA bridge。
- 游客设置页转登录、退出登录、清本机后，路由回到地图，菜单 / 设置 Portal 正常退出，入口表单不在 inert 子树中。
- 主动注入初次云读取 HTTP 503 后，等待超过自动保存防抖时间，旧本机进度没有被 PUT 到云端；`online` 后先恢复读取，成功恢复独立分区及云端进度。
- 挂起旧自动 PUT 时，重置立即提交空探索和空分区，保留设置；重置确认保持 busy，直到旧 PUT 完成且空 PUT 排队完成。云端最终为空，刷新 / 退出重登后仍为空。
- 云端 GET 已经读出旧状态后挂起响应，期间执行显式重置；放行旧 GET 不会把重置覆盖成旧进度。
- 清本机移除当前 / 旧探索键与本机会话，等待 1.4 秒仍没有立即回写空探索键；没有发送清空云端的 PUT。预先放入的不同云端进度保留，之后重新登录可恢复。
- QA 导出使用内存中的独立区域进度；普通页面即使不存在本地探索键也能导出当前经过清洗的内存状态。
- QA 调试打卡仍拒绝缺失 GPS 的状态。给浏览器提供模拟定位后，真实打卡按钮才可用；有效打卡先提交探索 / 独立分区，再等待正常 3.2 秒前奏进入演出。
- Space 跳过演出不改变存档；连续发现走 quick 队列；关闭演出开关清空队列但保留已提交进度，前奏之后不重新出现。
- reduced-motion 前奏为 0.4 秒，实际 GSAP 时间轴不超过 1.2 秒；结束后终态稳定且焦点在演出内，Space 可以返回地图，存档保持不变。

## 本次修复

1. `useAccountSession` 在云读取成功前阻止自动 PUT，避免初始读取暂时失败后用旧本机快照覆盖云端；失败后每 5 秒和 `online` 事件重试读取，显式重置仍能提交。
2. `usePageNavigation` 在进入懒加载菜单、HUD 变为 inert 之前保存触发者，经过设置返回菜单时保留原触发者；App 把该焦点传入菜单。菜单代理另有六档、右上账户入口与真实全屏 Portal 的独立验证。
3. App / Controller / Journey / MapController 接入经显式确认的显示副本；玩家公共存档锚点经 `displayPlayerUV` 投射到显示位置，持久化和云端白名单仍使用不可变公共锚点。

## 验收口径

正常 5.2 秒 / reduced-motion 不超过 1.2 秒指视觉时间轴。时间轴结束后保留故事终态供阅读，通过“继续探索”、任意点击、Escape 或 Space 离开；本次没有把保留阅读终态误判为动画持续运行。

浏览器输入来自 CDP 原生鼠标 / 键盘事件，定位来自浏览器 Geolocation Override，证明状态和浏览器接线闭环。现场 GPS、设备罗盘、手机触摸和实际听音不在这 37 项的证明范围内。

`results.json.errors` 中唯一 HTTP 503 是测试主动注入的读取故障，最终断言确认没有其他浏览器异常或请求失败。
