## 浏览器与对比度方法

使用同仓库 `127.0.0.1:5176`，独立临时 Edge profile、DPR 1，固定 QA 预设或隔离标定入口；没有真实账号 / token / 云端访问。测试浏览器退出后移除自有临时 profile。

新页面覆盖菜单及滚动底部、真实组件的合成长昵称账号、设置八分类及需要滚动的末项、下拉和确认框、Cinematic 故事终态、标定边界 / 点位 / 审查 / 手填坐标，至少各有 1440×900 与 844×390 两档。长账号帧通过不改动产品组件的临时 React root 传入合成 AccountUser，回调为空，不属于账号登录验证。

文字检查先记录实际前景色、透明度与行矩形，再暂时隐藏字色 / 字影，捕获同一布局的真实背景 PNG。对行矩形内缩后的背景像素逐点计算对比度，报告 **P05（第 5 百分位）**，正文 / 小字门槛 4.5；至少 24px 普通字或至少 18.66px 且字重 ≥700 的大字门槛 3。原始 minimum 与采样数也保留。

排除禁用 / aria-disabled、inert、aria-hidden、读屏专用、视口外、遮挡或不足约 60% 行高的裁切文字。原生表单取值 / placeholder 用控件内文本位置估算矩形；不据此声称逐字形覆盖。带描边的 SVG 标签单独核对前景与 halo 的颜色对比和屏幕描边粗细，不把地图底图误作字的直接背景。

新增页面的 645 项控件检查使用截图内侧 / 外侧的实际邻域颜色，并结合实际边框、填充、图标或伪元素颜色，门槛为 3。只对完全可见、中心没有被其他元素遮挡的控件评分，裁切控件待对应滚动帧中完整可见时检查。原生 checkbox / range 另从截图检查是否有至少四个指示像素达到 3；没有用其不可靠的 computed 原生背景代替浏览器绘制。旧界面 70 项是 resolved 边框 / 填充相对于相邻不透明父底的颜色检查，单独保留口径，不将其称为全部轮廓像素的扫描。
