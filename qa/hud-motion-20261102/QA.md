## 六档布局与交互

1920×1080、1440×900、1280×720、1024×600、844×390、667×375，各检查定位卡展开/收拢两态。HUD 交叠、可见地标文字对 HUD/其他标签交叠、出界、短边小于 44px 的按钮均为 0；每态收起的地标文字不超过 2 枚。原菱形、`data-testid`、经纬锚点不变。

真实鼠标/键盘覆盖：图鉴打开→焦点进入→带 inert 的退场→焦点归还；菜单/设置导航；Esc 逐级返回；快速开合三轮无残留。普通入口在独立临时 profile 中完成游客进入、UI 修改减少动态、localStorage 写回与刷新恢复，探索记录保持 7/8。没有读取用户实际账号、浏览器 profile 或云存档。

动效检查包括 0→37% 的可见中间值、圆弧/数字每帧误差不超过 0.55 个百分点、最终 37%；补间中打开减少动态直接到终态；系统与游戏偏好取或、系统偏好实时恢复；低画质/减少强闪光关闭装饰；启程前 HUD 隐藏且 inert，错峰进入后全部稳定。

## 两轮视觉评审

第一轮检查 `shots/review-1-desktop.png`：保留书法标题、玉纸与金线；发现定位区可能压住地标文字，随后增加文字避让，并提升存档说明对比度、为探索环增加可见标题。第二轮逐一查看最终桌面与手机截图，定位区与探索环均落在安全区，菱形可点、文字收束，中央地图保持清楚。

播放侧使用浏览器原生时钟与 rAF 采样，不替换时钟或推进虚拟时间。静帧布局阶段通过现有 `freeze()` 固定 Canvas；性能阶段恢复完整场景。早期强制 SwiftShader 软件渲染时出现 Canvas/WAAPI 停顿，因此为 QA 公共库新增显式 `hardwareRendering` 选项（默认行为不变），本轮使用 Edge 默认渲染并记录实际渲染器：Intel Iris Xe / ANGLE Direct3D11。

844×390、每档 5 秒、自动降级关闭、Canvas 正常运行：三档均约 60 rAF fps，逐帧原始结果以 results.json 为准。结果只证明本机该浏览器的帧调度回归，不能外推为手机 GPU 帧率、低功耗或公网体验。

DEV 调试接口新增 `setSettings()` / `setQualityPreset()`，用于操作应用正在使用的 store，避免 QA 通过动态 import 在 Vite 热更新后载入第二个模块实例。构建预览已断言没有暴露调试接口。
