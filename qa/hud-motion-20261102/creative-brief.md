# 理韵寻踪 · HUD 动效精调

依据 `apps/liyun-explorer/docs/UI-REFACTOR-PLAN-V2.md` 的 P3 / 5.1–5.4；在已有未提交的 M1/M3 工作区上增量实现。本轮只处理地图 HUD 与通往它的面板反馈。

旅人展开一纸校园地图，四角的工具安静落定；走过的风景在探索环中留下可见的痕迹。玩家是寻路者，地图是贯穿交互的媒介，玉绿、宣纸和金线沿用现有令牌。字体沿用已打包的 Noto Serif SC / Ma Shan Zheng（已查阅 local-font-library），不增加字体请求或美术资产。

进入世界的标志是关闭启程卡后 HUD 就位。值得稍作停留的是探索度增长：弧线与数字共用一次 900ms 补间，随后收束。HUD 不与打卡演出争抢高潮。

| 状态 | 因果与节奏 | 收束 / 中断 |
| --- | --- | --- |
| 进入 | 品牌和状态先出现，操作坞、定位卡、探索环随后；420ms 位移淡入，90ms 错峰 | 结束后不重复播放；减少动态时仅 90ms 淡入 |
| 静置 | 主操作一条低对比金线慢呼吸 | 低画质、减少动态、减少闪光、页面隐藏时关闭 |
| 操作 | hover 金线与亮度，press 90ms 下压，键盘有完整焦点环 | transform 单一引擎所有；离开即恢复 |
| 定位 | 默认按视口选择展开状态，可手动收拢，定位中明确 busy | 内容高度仅在该卡变化，四锚坐标不参与动画 |
| 打开 / 关闭面板 | 背景淡变，纸面短位移与缩放 | AnimatePresence 保留退场；退出中禁用点击，焦点回到触发按钮 |
| 增长 | 数字和弧线同一 MotionValue，900ms 单次增长 + 一次扫光 | 快速更新从当前值续接；减少动态直接终态；减少闪光取消扫光 |

视觉能量：进入 25 → 探索 12 → 操作 30 → 反馈 55 → 余韵 12。最多三个强视觉主体同时运动。无新增音效，静音下所有状态仍可理解。

验收：六档横屏静帧 + 时序取样；真实点击 / 键盘 / 焦点 / 快速开合；系统与游戏开关取或；低画质和隐藏页面停用装饰；进度中间值与终态一致。浏览器证据只代表本地合成视口，不作为真机性能或发布结论。
