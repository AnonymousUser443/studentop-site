# AidenOS · 聚光入境

## 体验命题

散落四方的微光先聚成名字，山水才被唤醒；访客上滑推开锁屏，验证后让这层夜色从四周散去，进入自己的数字案头。

- 访客经历：从安静、凝聚、显景，到明确的上滑与登录，最后释放。
- 访客角色：来到 Aiden 数字案头的人。
- 入境动作：上滑时钟锁屏，或者点击提示 / 按 Enter；只有同源服务端确认后才能进入桌面。
- 期待的瞬间：名字从粒子中稳定下来后，月环、山峦与倒影依次出现；成功登录后，外缘先散开，中心表单最后离场。

## 时间与分层

| 场景 | 层与动作 | 存在理由 |
| --- | --- | --- |
| 0–1.9 秒：聚字 | 墨绿底；四边粒子沿弧线聚到实时排版的 AidenOS 字形 | 先认出名字，保持中心焦点 |
| 1.7–3.3 秒：显景 | 实体标题接住粒子；月环、山水与倒影分层显现 | 用前后层次展开用户设计的世界 |
| 3.3–5.2 秒：停驻 | 标题与山水稳定，底部环形加载按钮持续转动 | 给画面一次呼吸，不伪造加载百分比 |
| 时钟锁屏 | 上方居中时间与日期；下方轻量上滑提示 | 清楚、安静地等待访客操作 |
| 上滑进入登录 | 时钟上移消退，壁纸变暗并模糊，头像与普通文本输入框出现 | 让手势和画面转变有因果关系 |
| 成功约 1.2 秒 | 遮罩从屏幕边缘向中心收缩，碎光向外飞散，中心表单最后消失 | 服务端确认后的一次完整释放 |

同时运动的强主体不超过三个。开机粒子使用固定种子和绝对时间；加载环是可跳转到锁屏的真实按钮。全程无自动音频。

## 状态与交互

首次访问本版开场时播放一次；可跳过或重播。上滑、鼠标滚轮、登录提示与 Enter 都可进入登录；Escape 返回时钟，提交或离场中的取消继续遵守会话撤销流程。

输入框始终为 type=text，不切换为 password、不用 CSS 伪装密码字符；保留 compositionstart / compositionend 与 keyCode 229 保护，中文选字时 Enter 不提交。输入仅经现有同源接口验证，提交后清空，不加入粒子采样、存储或日志。

桌面在动画结束前仍 inert；再次锁定、切后台或过期响应不能通过动画绕过门禁。减少动态使用短静帧 / 直接显现；不依赖 Canvas、图片或动画成功才能显示可用的登录界面。

## 检查范围

只检查本次开机、手势、中文输入、服务端授权后粒子离场及减少动态。使用合成问答 fixture 验证成功、取消和锁定，不读取或提交真实私密答案，不重跑理韵、体素或整站全流程。
