# Aiden 网页启动与门禁 · 设计简报

## 体验命题
访客先看见一个轻量、诚实的网页启动演示，再停在青玉山水前；进入桌面是明确的登录动作，不是点击背景的意外结果。

- 角色：来到 Aiden 数字案头的访客。
- 入境动作：时钟页的登录按钮或 Enter 打开问题表单；只有服务端确认才进入桌面。
- 视觉释放：简洁的等宽启动文字，转为用户指定的薄荷绿四窗人物原图，再让出山水锁屏。
- 媒介：窗格与纸页。保留原图轮廓、透明边缘，不重绘、不切散人物、不添加虚构硬件信息。
- 材料：现有 jade / paper / gold；正文 Noto UI，少量 Noto Serif 标题；无远程字体、音频或新框架。

## 节奏与状态
首次可持久化的浏览器访问：网页启动演示约 1.5 秒 → 原图标志约 2 秒 → 时钟页。启动可跳过，跳过不会授权。减少动态仅保留短静帧。刷新不重复演示；本地存储不可用时默认跳过，而不是无限重播。锁屏可手动重播，重播不执行登录。

时钟 → 明确登录 → 问题表单 → 请求中 → 服务端成功进入 / 失败继续输入 / 服务端冷却。Escape 只返回时钟；提交中的 Escape 会先保持门禁并撤销可能产生的会话。

## 边界
全界面仅显示 Aiden。答案不写入任何资源、文档、日志、URL、存储或前端校验常量。启动演示明确标注“网页启动演示”，不声称真实 BIOS 或硬件检测。公开静态内容不是加密保险箱；门禁授权来自同源服务端会话。

## 视觉验收
