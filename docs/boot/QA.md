- 成功 Cookie 可在刷新后恢复；主动锁屏立即 inert，DELETE 失败继续拒绝，刷新先撤销再表单；CSRF 轮换和 403 后只重检不重发。
- POST 请求期间锁屏、Escape、页面隐藏/恢复、快速重复操作；陈旧响应不得解除新门禁。
- 首次演示约 1.5s + 2s、刷新不重播、手动重播不登录；减少动态短静帧，设置/系统偏好变化可结束演示。
- 无 API、未配置、断网、超时、HTML 错误页均锁定但可重试；不读取浏览器存储中的旧授权值，不接受深链授权开关。

## 安全边界说明
公开静态内容并非加密内容库。这里只接受同源后端的授权响应；真实会话隔离、限次与撤销由后端强制执行。前端所有 API 调用排队，主动锁屏先遮蔽再撤销。跨刷新仅在 history.state 保存拒绝态布尔，绝不用于授予访问；localStorage 仅保存是否看过演示。

后端需额外覆盖：超时/断连的 POST 已被服务端接收后迟完成，不得在 DELETE 确认后重新创建有效会话。前端排队不能替代服务端事务顺序。
