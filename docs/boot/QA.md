## 安全边界说明
公开静态内容并非加密内容库。这里只接受同源后端的授权响应；真实会话隔离、限次与撤销由后端强制执行。前端所有 API 调用排队，主动锁屏先遮蔽再撤销。跨刷新仅在 history.state 保存拒绝态布尔，绝不用于授予访问；localStorage 仅保存是否看过演示。

后端需额外覆盖：超时/断连的 POST 已被服务端接收后迟完成，不得在 DELETE 确认后重新创建有效会话。前端排队不能替代服务端事务顺序。
