# 地图薄雾性能评估 · 2026-11-10

## 已确认的实现与运行情况

地图同时显示两套覆盖层：`MapScene` 内的 SVG `RegionVeil`，以及 `Atmosphere` 内 p5 驱动的 `FogField`。后者每帧遍历 330 个雾团，做视口剔除、旋转、透明混合、局部擦除和缓冲画布放大呈现。它已有降分辨率缓冲和精灵缓存，开销不是因为所有云纹都在逐像素重新生成，而是这些操作仍然持续重复。

线上页面本次检查使用高画质、完整动画，雾层和光效层各有一张 `2090 × 1192` 的画布；雾画布采样有实际像素内容。区域覆盖同时存在 10 个区域、10 张纹理引用和 10 个 mask。共享纹理文件仅 61,868 字节，重复引用不等于重复下载和解码。

本次地图发布版本 978 的 10 个区域合计 193 个顶点，未看到几何点数爆炸的证据。高画质虽然定义了 SVG 噪声滤镜，但部分引用位于半径为零的解锁圆上，不能把滤镜定义数量当作持续执行次数；极致画质另外把滤镜用于叠加纹理。

## 短测

- 线上静止地图：约 1.82 秒、111 个动画帧，帧间隔中位数约 16.7ms、95 分位约 17ms；此次短测没有持续掉帧。
- 本机隔离开发 QA 页、高画质、CSS 尺寸 `1258 × 727`、雾画布 `1572 × 908`：2.406 秒内雾层绘制 72 次，单次 JavaScript 绘制中位约 2.2ms、95 分位约 3.2ms，累计约 163.7ms。
- 保留最后一帧并暂停雾循环后，接下来 1.816 秒仅完成一次已排队的绘制。前后页面帧率都约 60fps；收益在减少持续工作量，不能据此宣称整体帧率提升百分比。

以上是桌面浏览器、短时间、静止相机的测量。绘制函数耗时包括 JavaScript 与提交调用，不代表完整 GPU 耗时，也不是移动设备实测。

## 推荐方案

**优先采用“缓存纸雾 + 按需解锁动效”。**

1. 地图区域遮挡统一由一套覆盖实现负责，移除旧 `FogField` 的常驻重绘，保留独立的光效与落叶层。
2. 预先生成或复用一张柔和云纹，根据锁定区域合成一个缓存的雾面。地图标定版本或解锁集合变化时才更新；平移和缩放主要跟随地图容器的 CSS transform。
3. 静止地图不做雾团计算。仅在刚解锁的区域播放约 0.3–0.8 秒的局部淡出或散雾，完成后停止并释放临时效果。
4. 默认不保留常驻噪声滤镜。需要轻微呼吸感时，可在相同区域遮罩下预合成两张略有差异的雾面，慢速交替透明度；应通过渲染跟踪确认实际合成方式，不能默认认为带 mask 的动画都免费走 GPU。
5. 缓存分辨率按目标显示尺寸与缩放档位设上限，避免为了省每帧计算反而分配超大地图纹理。相机变化不应重建区域路径；解锁边界继续使用当前发布的区域几何。

| 方案 | 保留的视觉 | 常驻工作 | 建议 |
| --- | --- | --- | --- |
| 单张缓存纸雾 | 云纹、区域遮挡、局部解锁淡出 | 最少；无雾动画循环 | 默认与移动端首选 |
| 两张预合成雾面交替透明度 | 纸雾增加轻微呼吸感 | 合成透明度与纹理占用 | 桌面可选，需实测 |
| 低分辨率动态 Canvas | 持续流动和翻滚 | 仍有持续绘制；应减少可见雾团与刷新频率 | 仅作为高档可选效果 |

先删除重复覆盖与持续重绘，再考虑细节优化；仅降低 `fogFps` 会保留同一套复杂度，并可能让云雾移动更不连贯。

本次仅完成评估和短测，未替换生产薄雾实现、未发布线上版本。
