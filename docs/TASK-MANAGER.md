# Web 桌面任务管理器

已在所有者本次授权下接入生产桌面和真实回环监控，实际验证、版本与回滚点见[生产发布记录](ACTIVITY-MONITOR-RELEASE-20261029.md)。以下开发测试与生产实采样分开留证。

基于团队主分支 `230f80d`，将用户既有 `rpi-task-manager` 静态界面接为原生桌面应用。入口在桌面、开始菜单、搜索和项目作品中的「窗口内打开」。应用为单实例，支持拖动、缩放、最小化及任务栏恢复。原工程、Python 采样器和SSH配置保持不变；上线仅更新本站的主页与认证代理。

## 数据路径

```text
本站任务管理器窗口
  → /task-manager/（同源独立文档，样式和主题隔离）
  → /__desktop/task-manager/{health,snapshot,processes,events}
  → 当前桌面服务端会话校验
  → 固定 127.0.0.1:8765 的既有只读监控服务
```

CPU 分核、内存、物理磁盘 I/O、网络、温度、进程和系统信息来自监控接口。历史只累积实际收到的样本；离线显示等待或不可用，断线保留最后样本并提示，不生成随机指标、假曲线或 GPU 利用率。

开发使用 `node tools/dev-workspace.mjs`，仍是五服务。启动器不启动 Python 采样器、不创建 SSH 隧道，也不停止或复用不明进程。监控离线不影响五服务健康。本机已有受授权的安全隧道或相容回环服务时可直接使用，否则窗口保持离线状态。`DESKTOP_TASK_MANAGER_PORT` 默认 8765，仅允许整数 TCP 端口，不接受 URL 或远端主机。

## 认证与生命周期

- 精确白名单仅接受 GET/HEAD，拒绝查询串、编码绕过、写入、重定向及跨源请求。不向上游转发访客 Cookie 或来源，不输出内部错误、私有响应头及未约定字段。
- 读取复用当前桌面会话，不新建或延长授权。SSE 每次转发前及空闲时复核授权；退出、过期、关闭认证服务后停止交付。连接数量、报文大小、读超时与背压均有上限。
- 最小化或页面隐藏停止 SSE 和在途查询；恢复后重连，保留手动暂停状态。关闭与锁屏立即销毁监控文档，清理流、请求、定时器和监听；解锁后可重新打开。
- 父子消息同时校验来源窗口和同源地址。主题只作用于监控文档，偏好存储键独立。
