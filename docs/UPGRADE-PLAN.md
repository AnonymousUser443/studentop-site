## 2. 个人主页设计规格
主题名：青玉纸境。保留Windows11熟悉的信息架构，不改成普通落地页。以用户指定沉玉谷壁纸为主体；玉绿、米白、柔金、少量朱砂组成纸张层叠UI。剪纸轮廓、细金边、短而有层次的投影；禁止全屏重模糊、霓虹和无依据的渐变卡片堆叠。
- 用户头像资产：site/assets/img/avatar-aiden.jpg；壁纸：wall-chenyu.webp，缩略图thumb-chenyu.webp，由Lead准备，保留原始外部文件不改动。
- 配置契约：SITE.profile.avatar（相对URL）；默认wall id为chenyu；保留现有window.SITE公共对象。
- 字体：有许可的本地Noto UI/Serif，正文清晰，标题少量书法点缀；新增中文必须纳入最终字库。
- 保留现有HTML DOM ids、Win/WM/Shell公共API与应用id。新CSS集中由主题成员维护；逻辑成员需要新增class时发送DOM约定，不能自行改CSS。
- 动画：窗口打开/关闭180–240ms、最小化/恢复220–300ms、面板180–220ms；响应prefers-reduced-motion与设置；取消/快速连续操作不得留下残态。

## 3. 校园入场设计规格
建筑方案已经照片目视核验冻结：以良乡文博中心的横向暖白巨框、通高柱廊、深青玻璃、中央圆鼓与方格雨棚为主景；以徐特立图书馆的水平厚框/成组竖窗/退台和综合教学楼的红砖/玻璃棋盘格为中景侧翼。来源与许可见BUILDING-REFERENCES.md。原创程序几何，保留空间行进节奏而不继续依赖重型游戏建筑资源。三处建筑的布局为艺术化重组，不称精确数字孪生。
- 构图：前景纸雕植栽/路灯、中景步道与校园门庭、主景可识别北理工建筑；远景简洁青色山层。暖纸色石材、砖红/铜色细节、玉绿树冠、金色晨光。
- 生命周期：加载→可交互迎宾→开始行进→门庭停驻→进入理韵；全程常驻跳过，支持键盘/触摸；不要自动播放声音。
- Three.js程序几何可用实例化/共享材质，无远程运行时资源；限制DPR与30/60fps，可降低质量、暂停后台渲染、释放资源。
- WebGL不可用/上下文丢失/初始化失败给静态可用入口，不留空白。减少动态提供短过渡或直接进入。
- DEV可观测状态与性能计数；生产不暴露测试控制。保持exit模块接口、skip参数和noscript入口可用。
