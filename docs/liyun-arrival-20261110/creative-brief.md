# 雾中寻路 · 一纸入境
旅人站在尚未展开的校园手札前；光线沿纸上的路线寻找校园，资源的真实进度让薄雾渐退。准备完成时，前景云纸向两侧分开，进入既有校园入口。
情绪：安静引入 → 轮廓浮现 → 路线聚光 → 纸图展开。意象为云纸、寻路金线、山水剪影。底色 #F5E6BD，主墨色玉绿，标题沿用已授权打包的马善政，正文 Noto Serif SC。
层次：远景静态山水；中景路线与地标线稿；前景两张轻纸云；信息层真实百分比。仅云纸与路线两组主体运动。资源未齐不能跳过加载，可跳过演出；减少动态模式无推镜与云纸位移。暖缓存不人为等待完整演出。
声音：不抢占自动播放权限，开场保持安静，沿用进入校园后的用户手势音乐。

## 1.1.1 地图薄雾修订
观众体验：在一张仍有云气流动的校园手札上寻路，纸图自然延伸到四周山水。观众是尚未踏遍校园的旅人；进入地图后，缓慢翻涌的云层持续邀请探索。解锁时短暂散雾，露出已到访区域，成为由遮蔽到发现的释放。
保留用户标定几何，已到访区域按原几何清雾，边缘羽化；空白边距仍延续同一片纸雾，避免在校园轮廓处露出底图的直线围墙。背景、图片、薄雾使用同一纸色与统一压暗层，不能出现亮色多边形贴在暗底上的切线。两组不同相位的云纹反向平移、缩放与轻旋转；低画质/减少动态静止，菜单/后台暂停，解锁淡出后回到 idle。不新增声音或素材下载。
