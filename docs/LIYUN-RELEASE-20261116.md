# 理韵寻踪 1.2.0 · 宣纸揭景与性能更新

本次按所有者 2026-11-16 授权，仅发布理韵玩家端和账号 API。源码基于已合并的 `8994314`，包含宣纸遮盖与打卡揭景、信笺与设置演出、Canvas 氛围、相机和标签布局优化、缓存修复，以及异步口令推导和有界登录队列。版本从 1.1.1 升至 1.2.0。

使用干净隔离工作区构建，不纳入校园网或文化舞台的未提交改动。`tools/prepare-liyun-update.mjs <审核的完整提交>` 封装不可变资源与四个固定账号源文件；`deploy/apply-liyun-update.mjs` 在共享发布锁下校验清单、配置和既有指针，原子切换前后端。

账号切换前暂时封闭公开 API 写入并备份私有数据库。升级保持 schema 2 和原进度／设置清洗契约，逐表内容摘要与记录数必须一致；摘要不包含在公开日志中。自检失败时在恢复公开写入前回滚代码和数据库；恢复写入后不自动覆盖玩家的新数据。旧不可变资源继续可访问。地图标定、团队工坊、主站、听潮、其他应用、DNS、证书及 frp 保留既有配置。

发布检查包含：前后端全部清单文件、账号健康与匿名权限、缓存端点、已发布地图摘要，以及相邻指针、配置和服务进程。清单负向测试覆盖源码偏移、进度契约改变、路径穿越、私有文件、重复成员、离线端点缺失及“数量相同但账号内容改变”。实际发布收据与公网验收完成后补入本目录。
