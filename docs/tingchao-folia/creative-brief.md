# 听潮 · 潮汐演出

情绪命题：让歌声像潮水一样靠近，字句在海面展开，停顿时把画面还给海。

听众是夜航／晨航的旅人。用户主动从“随行”切换到“演出”，才进入文字舞台；日常浏览保持安静。承载交互的是当前歌词，点击字幕能返回其演唱位置。惊叹点来自字句的空间排布与段落转场，而非持续闪光。

意象只保留海、潮光、字句。夜间继续墨夜蓝、松石绿、淡金、暖白；白天继续听潮已有的暖纸与青绿。渲染器从 CSS 变量取色，不使用随机主题、封面提色或上游主题库。动态歌词使用已有的全中文 Tingchao UI 字库，避免局部标题字库回退造成同一句内衬线／无衬线混排；曲名仍沿用原来的 Jade Serif。不增加字体。

能量曲线由歌词驱动：引入（元信息、空海）→展开（逐字出现）→变化（段落排布）→停顿（静帧）→释放（克制的镜头与转场）→余韵（最后一行）。不声称已有音频节拍分析；首版关闭模型推理与相应节拍特效。

前后景仍用已发布的原创昼夜海景，Pixi 只负责字句与低密度几何线条。保留顶部返回、模式、翻译、偏移与底部播放栏。小窗口、减少动态效果、WebGL 失败时回到已有逐字歌词，保证可读和可操作。
