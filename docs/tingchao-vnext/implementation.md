## 范围说明

云盘支持读取与播放已上传歌曲，不新增上传或删除操作。评论支持歌曲评论读取、分页、点赞与回复；测试使用本地隔离账号和数据。私密歌单要求登录自己的音乐会话。心动模式只使用固定 SDK 的 `playmode_intelligence_list` 返回曲目，使用喜欢歌曲及喜欢歌单作为上下文，不推断推荐算法或承诺额外功能。

桌面歌词叠加在 AidenOS 的浏览器桌面中，复用唯一音频运行时；主窗口关闭不影响播放或已开启歌词，锁屏隐藏歌词并使用原有锁屏媒体卡。

Folia Tilt 保留固定上游提交的分句与交错排字核心，换用本项目 Motion、容器布局、字体和 CSS 调色。仅真实逐字时间启用字级脉冲；小窗口、减少动态效果及初始化失败保持可读歌词。无新第三方运行依赖。
