## 故障与修正

开始菜单及搜索打开后，原逻辑会延迟强制聚焦输入框；手机键盘弹出产生高度变化后，窗口resize监听器又无条件关闭全部弹层，焦点回到任务栏，使菜单和键盘一并收回。

窄屏或粗指针设备现在先聚焦菜单容器，点击输入框后才输入；返回已固定应用也不强制进入输入框。延迟聚焦不会覆盖用户已经在菜单内选择的控件，桌面鼠标设备仍保留打开后直接输入。

手机只改变高度时保留面板、输入值与焦点；宽度变化或旋转仍关闭弹层并恢复触发按钮。开始菜单和搜索面板通过VisualViewport更新可用高度及底部偏移，兼容布局视口缩小，以及布局不变、可视区域缩小/平移的键盘模型。缩放页面不应用键盘补偿。搜索网页结果的SVG图标固定16px，避免窄屏结果行因默认SVG尺寸膨胀。
