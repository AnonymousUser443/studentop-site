## 2026-10-29 AidenOS 交互维护补充

本次开场与锁屏改动的[局部验证](boot/QA.md)另存证据，未重跑整站验收。后续修改登录交互时遵循：

- 问答输入保持普通 `type=text`，不添加密码字符样式；输入法组合期间及 keyCode 229 的确认回车不提交。动画不采样输入文字，提交、返回和锁定时清空。
- 禁用正在使用的输入框或按钮后，浏览器可能把焦点送到 body；验证和粒子离场期间把焦点留在锁屏，实测 Esc 能中止并撤销可能创建的会话。只测 DOM 合成事件无法发现全部焦点行为。
- 动画只能表现已确认的授权；结束前桌面保持 inert，重锁、切后台、过期响应不能放行。保留减少动态及 Canvas 失败的可用回退。
- 新文字先检查本地字体覆盖。主页补字可用 `tools/build-theme-fonts.py --site-only`，显式传入已授权源字体，不改动其他应用的资源或系统原字体。


## 验证环境

本次本地 Node 为 v24.22.0，npm 为 12.2.1。门禁、缓存、账号 HTTP 等测试只使用隔离的合成数据与临时回环服务，不读取真实答案或生产数据库。

受限沙箱曾阻止临时文件原子重命名与回环连接，出现 EPERM / EACCES。相同 Node 回归在允许这些本地操作的环境中通过；这类失败应记录环境和真实错误，先确认原因，再决定是否修改产品代码。不得删断言、放宽认证或改生产配置来消除环境报错。

本次[验证结果](../qa/maintenance-20261029/checks.json)记录实际命令与范围：Node 回归 93/93（其中门禁脚本内部另含 15 项合约）、理韵单测 71/71、三个应用及主页构建、素材清单与地图标定均通过。后续提交需在自己的版本上重新验证，不能直接引用本次数字作为通过证明。
